# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting form under **Security → Report a vulnerability**. The maintainer must enable private vulnerability reporting before the first public release. Do not place sensitive reproduction details in a public issue.

Include the affected version, reproduction steps, impact, and any relevant generated artifact. If the private form is temporarily unavailable, open a minimal public issue requesting a private contact channel without disclosing the vulnerability.

Security reports may include archive traversal, unsafe PPTX/XML handling, command injection, secret exposure, unexpected network access, hidden tracking behavior, or confidential material in release artifacts.
