# Synthetic Stage 5 feedback loop

This fixture proves four boundaries with original, synthetic metadata only:

1. a learning observation remains non-retrievable until a separate human admission matches its SHA-256;
2. an admitted observation becomes a private-runtime `learning` index record without entering the public catalog;
3. retrieval benchmarks fail on provider drift, missing expected candidates, forbidden candidates, or invented IDs;
4. legacy migration skips unadmitted and stale-hash sources while preserving local-private scope.
