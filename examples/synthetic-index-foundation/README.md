# Synthetic index-foundation example

This fixture contains only synthetic metadata. It demonstrates one public request over three providers:

- an original generic layout contract in the built-in catalog;
- an external metadata-only research pointer that cannot be materialized;
- a private local brand master that is valid for its owner but excluded from public-open-source retrieval.

No real template, master, logo, font, company data, or third-party media is included.
