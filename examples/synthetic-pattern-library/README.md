# Synthetic Pattern & Dataset Library fixture

This Stage 4 fixture proves two fail-closed paths using only synthetic requests
and public method metadata.

The comparison request resolves one registered Composition Pattern and two
linked Failure Patterns through separate Retrieval Receipts, then compiles a
coordinate-free Composition Plan. The unresolved request has no registered
match and emits no plan. `metadata-dataset-export.json` contains only admitted
public JSON metadata and explicitly excludes assets, copy, coordinates, fonts,
model weights, automatic promotion, and automatic aesthetic truth.
