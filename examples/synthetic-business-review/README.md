# Synthetic business-review example

This directory contains invented data for testing the five-stage workflow. It is not derived from an uploaded deck, real company, client, or internal template.

Use `brief.json` as the Logic input and `source-data.csv` as the only quantitative source. The expected sequence is:

1. Logic defines the decision question and source-backed claims.
2. Copy locks visible wording and assigns stable `copy_id` values.
3. Art Direction plans a native line chart, driver comparison, and action page using the central configuration.
4. Output builds an editable deck and stamps removable `clayz` custom properties.
5. Supervisor compares the approved packages, PPTX objects, and final renders.

No reference master or visual asset is supplied; the generated neutral theme must be used.
