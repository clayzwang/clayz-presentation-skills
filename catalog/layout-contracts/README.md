# Public Layout Contracts

This directory contains original, brand-neutral semantic topology only. A
contract declares selection metadata, named content slots, relationships, and
relative weights. It contains no theme, visual variant, final coordinates,
template, master, brand kit, logo, font, private data, or model weight.

Every file must be registered in `../records.jsonl`, hash-bound to that record,
human admitted, and selected through a retrieval receipt before compilation.
