# Copy语义图：标题、正文和连接

本版完全采用copy-graph/1.0，专业输入是Logic完整文字研究报告。先通读并登记全部storyline及相邻主链连接，再按页序逐层登记子标题、随后正文及页内辅链。每正文页一个H1，正文页数等于storyline数量。没有中间讲述稿，不用旧Copy稿件或方法作为输入。

每个head/body直接追溯原报告，逻辑多重连接有明确方向、类型和含义；标题正文按需使用，可同层并存。多维数组作为完整body或可追溯子集传给Art。不能因归纳而丢失关键解释、期间、单位、限定或可读性。

完整字段、命令和表格规范见 ../../../packages/contracts/copy-graph.zh-CN.md。接口首版无损透传Copy输出；Art只选择忠实呈现，不能重写、改结构或退回Copy，问题保留在原生审计。读者和Auditor职责及原生次数保持，结构检查不证明语义质量。
