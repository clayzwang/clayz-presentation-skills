# 一等公民 Index 门禁

新制作只有统一路径。公共方法与实际选用、可读取的资料进入同一个
CompositeIndex。个人配置文档不等于知识引用，也不会自动带来必需的私人
Provider ID、四类学习覆盖或持久版本学习门槛。

新索引证据的 mode 固定为 unified。实际选择的任务资料需要物化时，使用现有
来源清单和 materializer，保留真实来源、权利、字节哈希和适用阶段。声明为
必需的来源仍须逐项验证，不能把不完整物化标为通过。没有此类资料时，按现有
结构记录 owner_materialization 为 not-applicable，来源字段为空/null。
可选知识库暂不可用只是一项限制，不产生另一条制作路径。

个人配置的来源用于解释配置，不自动成为报告主题的事实证据。只有实际可用且
验证通过的持久知识快照才可复用；新增持久知识仍遵循现有讨论准入和真实宿主
写入/回读流程。普通制作不要求先建持久版本学习仓。旧模式值仅供历史记录核查，
不得用于选择新任务的执行路径。

按阶段真实问题检索，保留相关性排序和采用回执；没有匹配可以如实记录。记录
数量或“已读资料库”的陈述不能替代内容质量。

## 逐阶段门禁

批准每个阶段前：

1. 每阶段最多向锁定的 CompositeIndex 发出三次检索请求。每次必须包含实质性任务问题、具体阶段/页面决策目标、内容/格式/实现/失败诊断评分档、最低分和候选预算；空查询和只写资料源名称的形式化请求不能过门禁。
2. 回执须记录分项相关性得分和排名；只选择超过阈值的候选，抑制重复候选，并把每个选择绑定到具体采用目标及 `planned` 或 `material` 采用状态。
3. 必须覆盖实际任务清单为该阶段声明为必需的 `task-private-learning` 来源记录。阶段要求来自已锁定证据，不得硬编码来源名称或数量。
4. 将完整回执追加到 `index_evidence.stage_receipts.<stage>`。
5. 运行当前阶段验证器。缺少选择、来源覆盖不足、记录虚构、快照变化、仅写“已参考”或校准／绑定陈旧均失败关闭。质量问题、可选来源无匹配或延期检查要保留在阶段证据中，可以随产物传递；不得改写为 `pass`。

Index 只能通过“已选择且有回执”的记录影响决策。Independent Auditor 如需审计问题支持，可读取同一份锁定 Index，但不建立平行检索路径。记录 ID、来源 ID、哈希、Provider 快照、`never_copy` 边界和采用结果必须保留为可见证据。

## 实质门禁

有回执不代表内容自动合格。Copy 仍须通过跨页句法和短语变化检查；Art Direction 仍须通过内容特定首要视觉、轮廓连续重复、结构复用、主媒介多样性、量化编码和参考采用检查；Output 必须证明最终 PPTX 中存在计划要求的原生对象；Supervisor 必须针对最终 PPTX 重跑上游验证，并拒绝重复或不含页面身份的检查证据。
