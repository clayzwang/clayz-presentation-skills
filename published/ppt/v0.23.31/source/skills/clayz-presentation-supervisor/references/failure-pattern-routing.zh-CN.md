# Failure Pattern 路由

Failure Pattern 是可选、已登记的诊断知识。只有记录已人工准入、哈希有效、
权利允许，并且因实际失败信号出现在 Retrieval Receipt 中时，Supervisor 才
能使用。

必须把记录与重新打开的 PPTX 对象和真实渲染证据核对。矩形存在、对象数量、
相似度分数或单独的 Renderer 警告都不是质量真值。应记录证据、不确定性、
最早可预防 Stage 和 Pattern 中登记的修复责任方。Supervisor 只诊断和路由，
不执行修复，也不拥有独立学习库。

没有匹配的可用 Failure Pattern 时，应保留任务级证据并把可选知识标记为
`unresolved`，不得发明失败码、修复方法或晋升决定。

详见 `../../../docs/pattern-dataset-library.zh-CN.md`。
