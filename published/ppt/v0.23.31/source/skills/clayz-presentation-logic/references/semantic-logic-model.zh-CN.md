# 任务自身的语义

Logic 用完整论述解释题材与真实关系，保留定义、范围、证据强度和不确定性。复杂题材可补充语义资料，但不强制对象分类、消息树、父子节点合同、兄弟组语法或固定方法链。

不强制语义表单，不等于省略对研究范围及关系的判断。依据来源解释当前归纳为什么成立，辨认分类的重叠、层级和例外；必要的关系应在研究正文中可理解。研究中的分类和关系不自动对应演示章节、页面或栏数。

分析方法来自本次任务、个人配置或选中的外部知识，只作为专业判断的参考，不是工具内置的页面路线。Copy 负责内容分组及 copy_id，Art Direction 将其转为视觉结构。Logic 不预先决定最终措辞、布局或图形。

重复出现的事实与口径应保持一致，必要限制应明确；相关不能改成因果，无序事实不能改成流程。不确定性放在现有 story 和证据字段中。

完整故事和页面安排使用[当前 Logic 合同](logic-package-contract.zh-CN.md)。只要含义和证据可以独立理解，内容单元即可交 Copy，不依赖额外消息树。
