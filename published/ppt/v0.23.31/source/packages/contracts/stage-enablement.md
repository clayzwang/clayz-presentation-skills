## Authority and useful work

The user request, actually supplied facts and meaning are authoritative. Distinguish explicit requirements, bound preferences and proposals; do not invent confirmation, page limits, narrative archetypes or mandatory layout formulas. Routine research and reversible authoring within the task do not need repeated outline approval. State unknowns, missing sources and explicit release conditions honestly.

Offline component application consistency does not assert an official release. Use actual complete tool/knowledge bytes and real environment observations; package inspection is not a native Library, renderer or application acceptance probe. Inspection/advice/discussion learning are separate from production. Confirmed knowledge follows native-library-workflow; a draft or changed attachment is not a committed verified source.

## Research, expression and professional depth

Infer execution/research/mixed responsibility from the task and actual material, not word count or attachment presence. Execution preserves supplied meaning, numbers, qualifications, relationships and traceability while organizing expression. Research forms provisional questions, actually reads primary evidence, revises its framing, examines counterevidence and compares definitions/time windows/units before synthesis. Mixed work states the scope of each. No source count, prose length, elapsed time or page count proves depth.

Logic develops a full written explanation of facts, mechanisms, scope, evidence, competing interpretations and remaining limits before pagination. A source list, findings index or repeated conclusion is insufficient. Copy actually reconstructs that report into a meaningful main chain and page-level subsidiary relations; no middle account or old page-first package. Preserve necessary explanation, source ranges, exact units/periods and uncertainty. Natural prose and semantic judgment remain distinct from graph/schema checks.

Art preserves every Copy node, word, datum, relationship and page identity. It chooses grouping, medium, position, hierarchy and reading path from content responsibilities, not default cards or a fixed Storyline stripe. Read the bound knowledge’s relevant full node/CU text before designing/writing scripts, save actual host reads and concrete adoption/adjustment/non-adoption reasons. Knowledge methods are contextual, not a required number of shapes, arrows, layouts or retrieval hits. Content objections remain audit-only.

Output preserves the design’s native object boundaries and editable text/tables/charts/connectors. Native object existence is not observed move/edit/reopen behavior. Check actual data bindings, negative signs, units, fonts, margins/capacity, native reopen and every page image within the actual route. Preserve-name-defer-native keeps exact PPTX font identity and explicitly pending native acceptance; diagnostic substitution is recorded, never called exact-font success.

## Independent readers, bounded revision and audit

fast uses four authors and actual technical checks without independent-reader claims. normal/train use content/layout/final fresh readers, each directly from the prepared first packet. Freeze independent understanding before comparison. content alone may return once to Logic; layout once to Art; final once to Copy. Original readers confirm new affected versions; upstream changes invalidate dependent passes. Preserve every failure, used budget, remaining finding and unavailable original context. Do not add title-only gates, replacement readers or another repair cycle.

After the three current readers close, a separate fresh Auditor first reads the artifact and freezes understanding, then sees the original request, stage evidence and full reader history. It records findings only; it does not alter content, reclassify a failure for convenience or trigger another repair. Missing actual isolation is disclosed; the author is not its own independent reader. Shared filesystem role separation is not a security sandbox.
