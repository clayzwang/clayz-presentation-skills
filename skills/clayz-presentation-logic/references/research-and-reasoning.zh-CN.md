# 研究、来源与证据

完整研究是交付的主体。先写有事实、机制、关系、比较、证据和出处的完整报告，并保留可核查过程文件；摘要、编号发现或来源清单只是辅助材料，不能代替正文。具体段落和层次由实际论证形成，不先按PPT页或固定分组压缩。按stage-file-handoff/1.0把报告、过程、证据与数据分别保存，研究作者不接收布局/字体/预算快照。

根据题材和任务补足研究，优先原始数据、正式文件和权威来源。对时效信息核对有效版本；无法验证的内容明确列为假设或缺口。任务专用的分析框架来自用户明确要求或本次实际研究；选中的知识用于支持基础方法，不把行业案例作为默认研究方向。基础调查仍由 Logic 负责。不规定统一分析框架、提问清单、管理路线、动作模板或页面配额。

Logic 形成完整研究成果、证据与实质判断，不安排页面。Copy 组织演示内容、章节、分页、标题和具体文字；Art 决定呈现结构；不主动生成备注或附录。

## 以来源建立题材范围，再选择研究重点

把初始研究问题视为暂定。先依据用户目的阅读原始来源，从来源实际披露的内容建立题材的范围、组成及真实关系，再确定深入研究的重点。来源可能揭示最初没有想到的对象、用途或关系，也可能说明原先的分类不成立；相应修订问题和解释，不只摘取能回答原问题的证据。不同题材选择不同切入口，不把这些研究动作变成固定栏目或页面顺序。

研究取舍首先服务于这位读者需要理解的题材。事实的重要性也可以来自它对主体身份、历史变化、实际用途或关系差异的解释，不必以能否改变当期经营判断来决定是否保留。根据任务选择深度；不要求穷尽所有细节，也不把规模较小等同于没有解释价值。

同时检查判断与研究框架：除了为已有判断寻找反证，还要检查当前问题是否排除了重要对象、混同不同关系，或者把相互重叠、不同层级的内容硬归为并列分类。归纳应有证据支持的依据、范围和例外；个别事实有来源，不足以证明整体划分成立。保留真实的分类、联系、层级与变化，不能为了叙述整齐强建统一主线或固定数量的分组。

研究完成以用户需要理解的题材是否得到充分解释为依据；答完作者最初列出的问题不能单独证明完整。将研究范围及重要遗漏与用户目的、原始来源呈现的题材相互核对，补充必要解释，或说明有理由的取舍与剩余限制。先形成可独立理解的研究论述，再由 Copy 根据实际内容组织表达。上述判断保存在完整报告及实际研究过程文件中，不增加表单、计数或审批。

## 二、建立来源与证据台账

每个来源至少记录：`source_id`、名称、类型、作者／发布者、日期、定位、可支持的声明、限制、是否为一手资料。

### 来源优先级

1. 原始数据、正式合同、正式政策、监管文件、官方产品条款和用户确认事实；
2. 公司正式报告、权威统计、原始研究、经审计或可复核计算；
3. 可信行业报告和专业解释；
4. 新闻、访谈和二手综述；
5. 未核验截图、传闻和模型常识。

低优先级来源可以提出假设，不能单独支撑强因果、精确数字或高风险建议。

### 证据状态

| 状态 | 定义 | 允许写法 |
|---|---|---|
| 原始事实 | 来源直接陈述且口径清楚 | “截至7月，A为25%” |
| 直接计算 | 使用已知数据按明确公式得到 | “按同口径测算，A/B为1.46” |
| 解释性推断 | 证据支持但仍有其他解释 | “可能与……有关，需进一步验证” |
| 因果判断 | 机制、时序、量级和反例均较充分 | “X是本期变化的主要驱动之一” |
| 预测 | 对未来的条件性判断 | “若条件C成立，预计……” |
| 建议 | 基于目标和约束提出的选择 | “建议优先……” |
| 目标 | 主观设定的期望状态 | “建议目标为……” |
| 待验证假设 | 尚需证据的解释 | “待验证：X是否导致Y” |
| 待补数据 | 缺失且不能合理填补 | “【待补：区域口径数据】” |

## 三、统一术语和指标口径

### 指标字典字段

每个指标必须写清：名称、业务定义、计算公式、分子、分母、时间口径、统计范围、账号／记录去重规则、单位、小数位、数据源、更新时间、限制和展示格式。

### 常见错误

- 把当月、年累计和滚动12个月放在同一比较中；
- 把用户数、账号数、订单数、会话数、金额和价值混用；
- 同比和环比分母不同却直接比较；
- 目标达成率未说明目标版本或时间进度；
- 百分比变化与百分点变化混写；
- 总量变化由口径调整造成，却解释为业务变化；
- 图表显示值经过四舍五入，合计看似不等于100%。

先计算、复核和冻结数字，再写结论。条件性计算必须把条件写入台账。例如活跃用户数同比下降25%、同一用户群收入同比增长10%，只有两个指标覆盖同一批用户、同一期间和同一范围时，才能计算人均收入约增长46.7%；否则只能确认“用户规模与收入方向相反”。


## 判断与交接

主张强度应与证据相称，核对因果判断的证据、替代解释及适用边界；证据不足时保留不确定性。数字、定义、期间、分母、单位、公式和来源应可复核；汇总判断要有支持它的明细。不要把未知原因补写成结论。每个独立交接的内容单元应足以让 Copy 理解。页内分组及表达由 Copy 完成，后续环节检查页面连贯和信息覆盖。
