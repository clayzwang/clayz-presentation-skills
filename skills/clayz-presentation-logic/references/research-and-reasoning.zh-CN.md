## 一、先学懂题材

把“需要研究”拆成可检验的知识问题，不要笼统搜索主题。至少检查以下层次：

| 层次 | 必答问题 | 常见材料 |
|---|---|---|
| 背景 | 为什么现在要讲，过去发生了什么 | 历史材料、项目纪要、政策沿革 |
| 对象 | 谁受到影响，彼此关系是什么 | 用户群、数据实体、角色、团队、流程 |
| 机制 | 事情为什么这样运转 | 产品规则、业务链路、激励机制、物理／技术原理 |
| 口径 | 数字到底在算什么 | 指标定义、分母、期间、范围、去重和更新频率 |
| 外部环境 | 市场、行业、政策或技术发生了什么 | 官方文件、行业数据、原始研究 |
| 争议 | 哪些结论存在相反证据或不同解释 | 反例、替代假设、利益相关方意见 |
| 行动 | 哪些条件下能采取什么动作 | 权限、资源、时间、风险、前置条件 |

建立“知识需求清单”：问题、为什么必须懂、当前证据、计划来源、完成状态、未解决将限制什么结论。先补会改变主线和结论强度的知识，再补丰富案例的知识。

### 充分展开与适时收束

“完整”不是无限扩展。遇到汇总性表达时，先向下展开到足以判断的最小证据集合：例如“后续5个月”先列出5个月的目标、基线、假设和计算结果；“两种方案组合”先列两种方案各自的效率、稳定性、成本和边界；“总体有效”先列样本、口径与逐项观察。之后用四个问题决定是否继续：新增细节是否会改变主结论、关系判断、决策选择或最终表达。四项均否时停止扩展，把可复核但非上屏信息转入底稿、备注或附录。

### 研究边界

- 优先使用用户提供的真实材料、原始数据、正式制度和权威来源。
- 对会变化的信息检索当前版本；保留发布日期、有效期和访问日期。
- 法规、财务、合同和安全声明必须核对权威来源，不能只凭宣传材料。
- 专业题材先调用对应专项技能；本技能负责把专业结论写成准确、可理解的剧本。
- 无法验证时写成待验证假设或信息缺口，不用常识填空。

## 二、建立来源与证据台账

每个来源至少记录：`source_id`、名称、类型、作者／发布者、日期、定位、可支持的声明、限制、是否为一手资料。

### 来源优先级

1. 原始数据、正式合同、正式政策、监管文件、官方产品条款和用户确认事实；
2. 公司正式报告、权威统计、原始研究、经审计或可复核计算；
3. 可信行业报告和专业解释；
4. 新闻、访谈和二手综述；
5. 未核验截图、传闻和模型常识。

低优先级来源可以提出假设，不能单独支撑强因果、精确数字或高风险建议。

### 证据状态

| 状态 | 定义 | 允许写法 |
|---|---|---|
| 原始事实 | 来源直接陈述且口径清楚 | “截至7月，A为25%” |
| 直接计算 | 使用已知数据按明确公式得到 | “按同口径测算，A/B为1.46” |
| 解释性推断 | 证据支持但仍有其他解释 | “可能与……有关，需进一步验证” |
| 因果判断 | 机制、时序、量级和反例均较充分 | “X是本期变化的主要驱动之一” |
| 预测 | 对未来的条件性判断 | “若条件C成立，预计……” |
| 建议 | 基于目标和约束提出的选择 | “建议优先……” |
| 目标 | 主观设定的期望状态 | “建议目标为……” |
| 待验证假设 | 尚需证据的解释 | “待验证：X是否导致Y” |
| 待补数据 | 缺失且不能合理填补 | “【待补：区域口径数据】” |

## 三、统一术语和指标口径

### 指标字典字段

每个指标必须写清：名称、业务定义、计算公式、分子、分母、时间口径、统计范围、账号／记录去重规则、单位、小数位、数据源、更新时间、限制和展示格式。

### 常见错误

- 把当月、年累计和滚动12个月放在同一比较中；
- 把用户数、账号数、订单数、会话数、金额和价值混用；
- 同比和环比分母不同却直接比较；
- 目标达成率未说明目标版本或时间进度；
- 百分比变化与百分点变化混写；
- 总量变化由口径调整造成，却解释为业务变化；
- 图表显示值经过四舍五入，合计看似不等于100%。

先计算、复核和冻结数字，再写结论。条件性计算必须把条件写入台账。例如活跃用户数同比下降25%、同一用户群收入同比增长10%，只有两个指标覆盖同一批用户、同一期间和同一范围时，才能计算人均收入约增长46.7%；否则只能确认“用户规模与收入方向相反”。

## 四、形成经得起追问的结论

### 分析五问

1. **发生什么**：规模、趋势、结构、差距、异常和不确定性是什么；
2. **分布特征**：业务单元、人群、产品、触点、时间、地区和场景如何分布；
3. **为什么**：哪些驱动可量化，哪些只是待验证假设；
4. **意味着什么**：对目标、风险、机会和资源配置有何影响；
5. **做什么**：有哪些选择，优先级、责任、时间和验证指标是什么。

### 结论形成步骤

1. 写无解释的事实句；
2. 拆分结构与贡献，找出变化集中处；
3. 列出至少两个替代解释；
4. 为每个解释写“如果为真，应看到什么证据”；
5. 查找支持证据与反证；
6. 判断证据能支持事实、相关、主要驱动还是因果；
7. 写出边界、反例和仍需验证的部分；
8. 再形成页面主张、动作对象和逻辑层级，最终标题交由Copy撰写。

### 因果检查

- **机制**：X通过什么中间环节影响Y；
- **时序**：X是否先于Y发生；
- **量级**：X的变化是否足以解释Y的变化；
- **替代解释**：还有哪些变量能产生同样结果；
- **反例**：X存在但Y未发生，或Y发生但X不存在的情况；
- **一致性**：不同业务单元、时间、样本是否方向一致；
- **干预证据**：采取或停止X后Y是否随之变化；
- **边界**：因果只在哪些范围、时期和条件下成立。

因果证据不足时，把“因为”改为“与……同时发生”“可能受到……影响”“待验证的主要假设是……”。

### 证据强度与主张强度

| 证据 | 主张可用强度 |
|---|---|
| 单一截面或个案 | 描述事实、提出问题，不下普遍因果 |
| 多期同口径趋势 | 判断趋势与拐点，因果仍需机制 |
| 结构贡献可量化 | 写“主要贡献／拖累来自……” |
| 多来源、机制与反证一致 | 写“主要驱动之一” |
| 可靠实验、准实验或强干预证据 | 在边界内使用因果措辞 |

## 五、把结论转成决策与动作

### 决策内容

建议页至少准备：需要决定什么、可选方案、评价维度、推荐方案、收益、成本、风险、前置条件、不可逆点、何时复盘和失败时如何退出。不要只写“建议加强”。

### 动作内容

一个可执行动作至少包含：对象、责任主体、动作、完成时间、目标状态、衡量指标、追踪频率、所需资源和依赖，并通过 `action_traceability` 指向直接引出该动作的差距、证据或机制节点。若数字证据只支持诊断，不足以支持方案，先安排验证动作而不是直接大规模推广。没有证据映射的“工作要求”不得作为L3管理落点进入定稿。

### 案例到机制

案例不能只展示好结果。写齐原始情境、关键矛盾、采取动作、结果、为什么有效、适用条件、不可复制部分和下一步。把个案总结成可验证机制，不把单个优秀样本包装成普遍规律。

### 复盘到新认识

复盘不能停在“亮点／不足／建议”。写清原假设、干预、观察结果、哪条原认识被推翻或保留、形成什么新认识、下一轮用什么指标和时间窗验证。只有观察没有认识变化时，仍是项目记录，不是试验学习闭环。

## 六、形成可交接的逻辑任务

Logic不写最终标题、正文、标点、断句或演讲备注。交给Copy前，每页只需确保：

- 根主张包含必要的主语、对象、时间、范围、证据强度和边界；
- 每个子节点只承担一个对象、动作、证据、机制、结果或限制；
- 同级组的分解维度一致，能够由Copy写成平行文案；
- 数据标签、显示值、单位和比较基准在语义上可分离；
- 需要讲者解释的证据口径、追问边界和过渡意图有明确逻辑来源，但不预写最终台词。

若一个节点必须依靠冒号、逗号或换行才能表达上下级关系，说明消息树仍未建好；先拆节点，不把结构问题交给Copy。

## 七、特殊内容类型

### 培训与一线宣导

- 先写“为什么与我有关”，再讲方法；每个概念配一个真实情境或微案例。
- 用生活化语言解释术语，允许简化表达但不改变产品、政策和数据含义。
- 练习题写清情境、任务、输出和参考判断；不要只写“讨论5分钟”。

### 政策与产品

- 分开写现行规则、变化点、影响对象、适用时间、例外、示例和行动要求。
- 定价、服务等级、使用权限和例外条款必须来自正式资料；示例明确假设。

### 领导讲话与大会材料

- 强判断必须有事实底座；口号页前后要有证据或行动承接。
- 使用克制、真实的情绪，不虚构危机、胜利或共识。

### 数据分析

- 数据页脚本包含比较基准、异常点、贡献拆分、管理含义和下一步验证。
- 多个彼此相关的数据必须先在底稿中统一期间、口径、对象和计算关系；不要把孤立数字拼成若干结论句。
- 不预先指定图表类型；只写清要比较什么、哪些数是重点、真实语义是什么。

## 八、终审清单

- 每个核心数字能否在30秒内找到原始来源或公式；
- 每个“因为”是否通过因果检查；
- 每个建议是否由差距和目标推出；
- 每项行动是否能定位到具体证据节点、责任主体、衡量指标和下一复盘时间；
- 每页删除后是否产生明确的信息缺口；
- 相邻两页能否用一句因果、问题、时间或决策关系连接；
- 同一指标、角色、产品和用户群名称是否全稿一致；
- 每个节点是否能够独立交给Copy，且不依赖标点、换行或视觉位置维持层级；
- 受众是否能复述总论点、章节判断和下一步；
- 是否仍有需要视觉设计师补写的空白内容；若有，内容未定稿。
- 是否有“未来N期、平均、总体、组合”等汇总句却找不到对应明细与公式；若有，内容未充分展开。
