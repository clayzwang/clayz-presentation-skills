# 原子文案与层级写作

## 先看树，不先看句子

每页先列 `node_id → primary_copy_id → text`。任何一句话同时回答“上位类别是什么”和“下面有哪些项”，都可能把父子压平。

### 冒号测试

看到“标签：A、B、C”时逐项判断：

1. 标签是否是A/B/C的上位概念；
2. A/B/C是否为同级并列或同序步骤；
3. A/B/C是否需要各自继续解释、映射图标、责任、数据或动作。

任一为“是”，标签与各子项必须拆成独立 `copy_id`。冒号可以留在完整句内部，但不能承担未建模的层级。

### 去符号准备

PPT的视觉层应接替标点承担层级和关系。Copy先把“标签：内容”“条件：结果”“方案：数字”拆成可映射的父子、条件、证据和结论单元，再尽量删除仅为模拟排版而存在的冒号、分号、斜杠和括号。下游可用位置、面积、对齐、嵌套、连线、汇聚、图表或表格表达；Copy不指定其中任何一种。

### 逗号测试

逗号、顿号、斜杠和“及/与/并”连接两个可独立执行、比较或追踪的事项时，通常应拆成同级原子单元。固定术语和不可拆短语除外。

## 标题与Storyline

- 标题回答“本页最重要的判断是什么”，优先为结论句，不写“情况介绍”“下一步建议”等空标签。
- Storyline回答“讲者如何用一句话把主张与正文联系起来”，必须是一句、单行、逐字锁定的完整句。
- 标题和Storyline可映射同一根节点，但使用两个不同 `copy_id`；根节点的主文案通常是标题，Storyline为补充文案。
- 不用Storyline重复标题换词，也不把正文清单串成一句长句。

### 标题模式路由

| 页面任务 | `title_mode` | 写法 |
|---|---|---|
| 事实／总览 | `factual-status` | 写清对象、期间和状态，不提前夸大原因 |
| 经营诊断 | `analytical-judgment` | 结论＋关键比较或集中处 |
| 机制／政策 | `mechanism-rule` | 改了什么规则、如何运行、带来什么行为变化 |
| 行动／决策 | `action-directive` | 谁针对什么差距采取什么动作并如何检验 |
| 转场／章节 | `transition-assertion` | 一句推动受众从当前认识进入下一阶段的强判断 |
| 培训／SOP | `instructional-action` | 本页要完成的具体操作与检查点 |

标题不是一律短句。经营重页可用“主题标签＋完整判断”的两段式语法；转场页则应短而有方向。是否单行由文案职责和主动断句决定，不以缩字换单行。

## 同级平行

给每个兄弟组写明确 `grammar_signature`：

| signature | 结构 | 示例 |
|---|---|---|
| `verb-object` | 动词＋宾语 | 优化上手引导；明确权限默认值 |
| `noun-category` | 名词性类别 | 上手引导；权限设置 |
| `problem-impact` | 问题＋影响 | 功能不足，难以匹配用户阶段；入口模糊，影响采用效率 |
| `metric-value` | 指标名＋显示值 | 激活率 62%；周留存率 41% |
| `stage-action` | 阶段＋关键动作 | 试点期：验证规则；推广期：复制机制 |

同组至少检查：词性、主语、动词时态、语气、粒度、标点和大致长度。长短差异本身不是错误，但如果一项只有四字标签、另一项是三句解释，通常说明层级未拆开。

## 数字与标签

数字不可埋进泛化句。一个KPI至少拆为指标名、显示值和单位；比较基准、期间和口径可作为相邻注释或脚注。Copy锁定显示值与标点，Output只决定空间关系与视觉权重。

## 主动断句

`text` 保持无换行的标准文本；需要人为断句时记录字符索引。断句不得切开：数字与单位、专有名词、实体名、产品名、量词、否定结构和固定短语。自动换行导致语义破坏时，Output必须调整宽度、字号token或回流，不得修改文字。

## 系列页语言

- 固定用户群、产品、角色、指标和阶段名称，保持Logic锁定顺序；
- 标题中保留可识别的系列母题，同时明确本页新增判断；
- 递进显影页可重复已建立的短标签，但不要重复解释性长句；
- 政策系列保持“升级亮点→政策设计→预期效果”的讲述顺序；
- From／To必须写出旧约束、规则改变、行为变化和结果，不能只用“复杂→简单”“分散→协同”充当机制；
- 系列之外，不复制同一“四字词＋解释”的空模板。

## 去AI味检查

- 删除不提供信息的“赋能、助力、全面、持续、进一步”等套话，除非它们具有可验证含义。
- 避免所有子项都写成同一种空洞“四字词＋解释”模板。
- 让动作有对象，让判断有证据，让目标有期限或衡量口径。
- 不为了显得完整而补出没有来源的第三项。
- 不在一个文本框里用冒号、分号和换行模拟三层结构。
- 不连续生产“xxxx：xxxxx”式标签句；同页多次出现时回查是否仍有未拆开的层级、映射或计算关系。
- 不在困局和取舍尚未建立时用宣导口号替代管理请示。

## 回流条件

遇到以下情况退回 Logic：父节点不能概括子节点；兄弟项无法使用同一语法；一个节点需要同时承担两个语义角色；文案只有补充新事实才能成立；标题与证据强度不匹配；一页存在两个无法共享主张的内容中心。
