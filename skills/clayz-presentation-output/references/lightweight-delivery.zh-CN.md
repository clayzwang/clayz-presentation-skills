# 轻量传播交付合同

## 默认与例外

用户未提前指定时，`delivery_profile=lightweight`。高清、印刷、超大屏、像素级图片还原或保留原始媒体属于显式例外；不能从“Pro模式”“图片很重要”或“源文件很清晰”自行推导为高清档。

轻量档面向中央配置声明的播放应用、普通办公设备、消息或邮件传输以及常规投屏。优化顺序是：减少不必要媒体 → 按实际显示框缩放 → 选择合适格式 → 清理重复／未使用对象 → 检查附件与字体 → 重新渲染。不得以整页栅格化、把中文转图片或破坏可编辑性换取体积。

## 位图准备

在图片插入PPTX前运行：

```powershell
python scripts/prepare_raster_asset.py source.png output/asset `
  --profile lightweight --role illustration `
  --placed-width-in 6.8 --placed-height-in 4.5 `
  --report output/asset-report.json
```

以最终显示框在96dpi下的像素为基准，轻量档通常保留约1.75倍线性分辨率；不得无条件保留原图。全幅位图通常不需要超过1600至1920像素长边，半页插图通常不需要超过1200至1600像素长边。若图片会被明显裁切，以覆盖裁切框所需的分辨率计算，不按“完整原图全部保留”计算。

格式路由：

- 照片、复杂不透明AI图、整页背景：JPEG，轻量档质量默认86；关键渐变或品牌主视觉可局部提高，不切换整稿档位。
- 透明背景插画：PNG；轻量档优先256色量化，人物肤色、渐变、半透明阴影和柔软边缘必须以最终页面渲染比对，出现可见色带或锯齿时仅该图保留真彩PNG。
- 系统截图、含小字UI、二维码、线稿：PNG；不使用有损JPEG，不做会破坏小字与编码识别的调色板量化。先裁到与步骤相关的区域，再按显示框保留约2倍分辨率。
- Icon、简单图形、流程、表格和图表：优先SVG、DrawingML或原生对象；不要先转成大PNG。

## 非图片体积

- 不默认嵌入中央配置中的首选字体或整套字体家族；字体正确渲染由任务级字体环境和最终重开探针保证。只有用户明确要求离线字体封装且许可允许时才可嵌入。
- 不保留未使用和重复的图片、音频、视频、OLE对象、Excel附件、隐藏媒体、外部链接缓存或多余预览。
- 相同素材重复出现时复用同一媒体内容；不要为每页生成一份像素完全相同的副本。
- 图表尽量只保留保证原生可编辑性所必需的数据。由图表关系明确引用的嵌入工作簿属于原生图表结构，不按无依据附件处理；无图表关系引用的工作表、整本Excel、OLE对象或源数据缓存仍须清理。
- 只保留中央配置选定的主题或母版所需结构，不复制无关主题、版式和Master；不得通过破坏继承关系换取体积。

## 体积审计

最终写盘后运行：

```powershell
python scripts/audit_pptx_size.py final.pptx `
  --profile lightweight --report ppt-size-audit.json
```

如果审计只发现精确重复媒体，可运行：

```powershell
python scripts/deduplicate_pptx_media.py final.pptx final-deduplicated.pptx
```

合并后把新文件视为新的最终PPTX，重新执行全部渲染、字形探针、目标应用兼容和体积审计；不能沿用合并前的报告。

轻量档对10至15页普通材料以1至2MB为优先目标；图片较多、截图密集或业务必须保留复杂透明插画时可以超过，但不得因此放宽单项效率检查。总大小是软预算，以下是默认返修项：

- 精确重复媒体；
- 没有任何关系引用的未使用媒体；
- 未经用户要求嵌入的字体、音视频或附件；
- 位图分辨率明显超过其最大显示框需求；
- 大体积不透明PNG本可安全使用JPEG；
- 依靠隐藏页、画布外对象或源文件缓存保留的大媒体。

完成优化后重新打开并渲染最终PPTX，逐页比较文字、透明边缘、人物肤色、渐变、截图小字、二维码、页码与母版。体积下降不能覆盖任何渲染或兼容性失败。
