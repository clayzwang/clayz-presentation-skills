# Composition Plan Consumption

Output consumes an Art Direction-approved Composition Plan; it never selects or
replaces a Composition Pattern. Verify the resolution and every receipt ID,
confirm the selected pattern and linked Failure Patterns remain registered and
hash-current, and reject any plan that claims coordinates or consumes Theme,
Visual Variant, Layout Contract, or Layout Tree during pattern compilation.

Use the plan's semantic mapping, task constraints, expected visual effect, and
failure guards together with the independently approved Layout Contract or core
Layout Tree. Resolve coordinates only inside Output. Preserve editable object
requirements and return any semantic conflict to Art Direction rather than
silently choosing another pattern.

See `../../../docs/pattern-dataset-library.md`.
