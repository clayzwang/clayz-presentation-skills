# Pattern Library 路由

Composition Pattern 的选择属于 Art Direction。请求只能来自已批准的任务
模式、页面职责、语义关系、目的标签、语言、约束和预期视觉效果。只能选择
Retrieval Receipt 中实际出现、已登记、人工准入且可物化的记录。

所选 Pattern 关联的 Failure Pattern 必须通过第二张 Receipt 解析，之后才可
编译 Composition Plan。必须记录选择原因、被拒绝候选及原因、约束、预期视觉
效果和两张 Receipt ID；不得保存隐藏推理，也不得声称使用未召回的方法。

Composition Pattern 只描述语义到空间的映射，不选择 Theme、Visual Variant、
Layout Contract、坐标、Renderer、模板、资产或文案。没有唯一可用 Pattern，
或关联 Failure 缺失时，必须记录 `unresolved`，并继续使用 Art Direction
核心方法，但不得声称选择了具名 Pattern。

Reference 与 Sequence 记录只能作为 metadata-only 决策证据，可以辅助比较和
系列判断，但不能授权复制源原文、媒体、坐标、字体或品牌视觉。

详见 `../../../docs/pattern-dataset-library.zh-CN.md`。
