# Pattern Library Routing

Composition Pattern selection is an Art Direction responsibility. Build the
request only from approved task mode, page role, semantic relations, purpose
tags, locale, constraints, and expected visual effect. Select only a registered,
human-admitted, materializable record that appears in its Retrieval Receipt.

The selected pattern's Failure Pattern links must be resolved through a second
receipt before a Composition Plan may be compiled. Record the selection reason,
rejected candidates and reasons, constraints, expected visual effect, and both
receipt IDs. Do not store hidden reasoning or claim an unretrieved method.

Composition Pattern describes semantic-to-spatial mapping. It does not choose
Theme, Visual Variant, Layout Contract, coordinates, renderer, template, asset,
or copy. When there is no unique eligible pattern or a linked failure record is
unavailable, record `unresolved` and continue through the core Art Direction
method without claiming a named pattern.

Reference and Sequence records are metadata-only decision evidence. They may
guide comparison and series review, but they never authorize copying source
wording, media, coordinates, fonts, or brand identity.
