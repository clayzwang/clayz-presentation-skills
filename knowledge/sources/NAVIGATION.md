# Shared source navigation

Store source material by file type so that Logic, Copy, Art Direction, and Output can retrieve the same asset without duplicating it:

- `documents/`: methodology, language, narrative, visual, technical, and provenance documents;
- `data/`: structured data and non-registry analytical inputs;
- `images/`: raster references and task-approved images;
- `svg/`: icons, charts, tables, layouts, and other vector assets;
- `pptx/`: user-owned masters and admitted presentation references;
- `pdf/`: admitted documents and presentation references.

Source directories are empty in the public distribution. Add only material you are authorized to use. Register each retrievable item in `../registry/asset-registry.jsonl`; generated outputs remain outside this source tree unless a human explicitly admits them.
