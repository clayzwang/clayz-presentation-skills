# Copy learning navigation

Use this area for reusable observations about titles, storylines, terminology, atomic copy, hierarchy, punctuation, line breaks, labels, notes, language register, and audience readability.

- Retrieve only material relevant to the current audience, text role, and language.
- Append task-grounded observations to `learning-records.jsonl` only after completion.

- Do not store page composition, coordinates, visual styles, private source material, or generated decks here.
- Do not promote frequently used wording automatically; require a human admission record.
