# Art Direction learning navigation

Use this area for reusable observations about first visual, hierarchy, dominant medium, semantic layout trees, density, reading paths, whitespace, silhouette, motifs, series behavior, A/B prototypes, and visual regressions.

- Search by page purpose, relationship, medium, density, and sequence role before opening examples.
- Inspect only a small admitted reference set plus useful physical or semantic neighbors.
- Append task-grounded observations to `learning-records.jsonl` after rendered comparison.
- Record what to learn and what must never be copied from each reference.
- Do not let automated scores, similarity, saliency, or usage count promote a reference automatically.
