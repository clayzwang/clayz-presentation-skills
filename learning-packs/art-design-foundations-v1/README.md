# Art design foundations v1.0.0

A separately downloadable, code-addressable learning pack for Clayz v0.20.2. It is not a layout/template library, a mandatory style, or human-admitted owner knowledge.

Read `Art-design-learning-v1.0.0.zh-CN.txt` for the complete Chinese learning text, including every principle, 33 paired teaching examples, source mapping and an eleven-step worked example. `nodes.json` is the machine-readable tree; `sources.json` records primary curriculum observations; `worked-example.json` contains concrete conclusions and actions.

From an extracted plugin, run:

```sh
python scripts/art_learning.py validate --pack /path/to/art-design-foundations-v1
python scripts/art_learning.py lookup --pack /path/to/art-design-foundations-v1 --code A06
python scripts/art_learning.py lookup --pack /path/to/art-design-foundations-v1 --code P.PER.HIERARCHY
```

FLOW lookup returns its selected principle nodes; a leaf lookup returns only that principle. Use the returned receipt only after actually reading the material; explain its application in Art's cognition record. Integrity checks verify coverage and bytes, not learning, aesthetic quality or factual correctness.

Public university curricula support the subject mapping. All principle wording, codes, PPT adaptations and cases are original synthesis, not quotations, institutional endorsements, observed classes, actual student work, or validated reader outcomes. Historical and supporting-discipline sources are labeled. No third-party images are redistributed. All eleven cognition steps should reach contextual conclusions and actions. Revisit affected steps when necessary; they are not eleven agents or approval gates.
