# Provenance policy

Classify every outside source as one of:

- `conceptual-inspiration`: an idea influenced the design; no code or asset is redistributed;
- `adapted-code`: identifiable code was modified; retain the original notice and license;
- `dependency`: a separately installed package is used at runtime;
- `redistributed-asset`: a file is included; record title, author, source, license, and modifications.

Record exact versions or commits when available. Do not represent conceptual inspiration as code reuse. Do not redistribute media merely because the surrounding repository has a permissive software license.

Private reference material is not part of the public provenance manifest. Keep its filenames and metadata outside the public repository.
