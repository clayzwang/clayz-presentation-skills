# PowerPoint COM fallback adapter

This Windows-only adapter consumes the same Clayz render-manifest contract and uses one PowerPoint process for authoring, saving, notes, and optional full-deck rendering. It supports text, common shapes, lines, raster images, SVG insertion through PowerPoint, and tables. Charts require the python-pptx or Artifact Tool route.

It is an operating-system fallback, not a host-model dependency.
