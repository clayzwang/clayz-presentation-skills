# 单轮返工与原读者复看 — v0.20.5

当前默认 `consolidated-once`：Copy 完成交付 → 标题读者、全文读者各自独立阅读同一版本 → 合并问题 → Copy 最多返工一轮 → 两位原读者分别复看，逐项确认已修复/仍存在并记录新问题 → Art → Output → 成品读者 → Art 或 Output 最多返工一轮 → 原成品读者复看 → 独立 Auditor 只记录，不触发返工 → 报告与交付。

两次“最多一轮”分别计数。复看是确认，不是新一轮返工授权。没有问题时不返工；返工后即使某位读者原先无问题，也要复看其对应范围。不得换读者冒充原读者确认，不得改写首次意见，不得另建 cycle 重置额度。原上下文不可恢复时如实记录证据不完整。

残留问题、新发现问题、未通过的实际检查都写入审计报告；不得为得到 clean 而进入新循环。独立 Auditor 的建议只进入后续任务或版本。文件身份、哈希、任务绑定和真实执行记录仍须有效。

执行命令、完整字段和兼容规则见 [reader-cycle.md](reader-cycle.md)。原始审读记录格式见 [reader-review.md](reader-review.md)。
