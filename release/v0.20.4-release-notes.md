# Clayz Presentation Skills v0.20.4

Iterate by developing the professional knowledge that produces design judgment: an observed problem or improvement opportunity leads to relevant domains, concepts, mechanisms, applicability and connections; Art then makes a contextual choice and observes the result. Cases support understanding. Page-specific repairs remain practice records.

This release promotes audience-aware industry research guidance and native production methods exercised during the two locally retained ten-round iterations: measured semantic tables, text flow and explicit phrase protection, scoped source links, optional font-bound calibration, real native previews, table/text bounds, immutable first-read sources, and stale technical-evidence rejection. The report title now prefers a matching visible cover title over unrelated smaller text. Knowledge enrichment, application and observed reader effect remain separate.

The current knowledge pack **1.2.8-industry.10-knowledge-first** is stored separately in [work-output](https://github.com/clayzwang/work-output/tree/main/knowledge/ppt/v0.20.4). Access to that repository is required. `config/knowledge-release.json` binds the exact archive and manifest hashes. The public release contains Cloud Light, Local Light, the Windows CPython 3.12 offline add-on, and SHA256SUMS.txt. The historical original teaching pack remains in source for backward-compatible tests; it is not republished as the current pack.

Validation covers repository regressions, real LibreOffice smoke, archive structure and checksums, and compatibility with the external pack. Local experiments and automated checks do not establish a measured aesthetic or human-reader improvement. Historical same-context audit limits remain disclosed. PowerPoint/WPS native acceptance is not claimed.
