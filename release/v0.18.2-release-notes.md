# Clayz Presentation Skills v0.18.2

Copy now reviews the argument before assigning text roles: the page question,
supported judgments and evidence, useful optional local headings, entity and
accounting scope, and the contribution of each passage. Art returns specific
medium-induced repetition or unclear grouping to Copy; Supervisor reads both
the text and the actual page. Existing semantic reviews and work notes carry
the observations. There is no heading quota, fixed three-level template, new
approval form or automated language-quality score.

The native comparator, Output QA validator and deviation-log validator support
`--result-json <path>` for automatic, scoped execution, record-integrity and
quality results. Actual failed QA checks and remaining issues are quality
findings, deferred/uncertain checks preserve coverage gaps, and invalid statuses
remain record errors. Exceptions do not imply a content failure or a quality
pass. Original messages and nonzero outcomes are preserved. A valid deviation
record does not certify a PPTX.

Strict native comparison now checks Art-approved table headers and rows at
their exact named cell locations. It accepts approved table content while
still detecting changed or missing cells and unrelated text. Deviation-log
validation reads Copy-owned pages in package 3.3 instead of dereferencing the
intentionally null Logic layer.

Copy 3.3, Art 2.2 and the existing native editing boundaries remain in place.
Regressions exercise real native tables, changed/missing cells, unbound text,
CLI diagnostics, honest failed/deferred QA, tool exceptions and null Logic
handoffs. Release automation also runs the repository suite, actual LibreOffice
smoke and archive/checksum verification. These checks do not claim PowerPoint
or WPS native acceptance.

## 中文

Copy 在分配文字角色前先组织问题、判断、证据和段落关系，并实际审读标题与证据
是否对应、局部标题是否有助理解、对象口径是否清楚、每段是否增加信息。局部标题
按内容需要使用。Art 将媒介造成的重复或含混分组交回 Copy，Supervisor 同时看
文字和实际页面。继续使用现有语义复核和工作记录，不增加标题配额、固定三层
模板、审批表或自动语言评分。

原生比对、Output QA 和偏差记录验证器新增 --result-json <路径>，自动分别记录
工具运行、记录完整性和检查范围内的质量结论。真实 fail 和未解决问题归质量发现，
deferred/uncertain 保留未验范围，未知状态值仍是记录错误。异常不能直接推断
正文错误或质量通过；保留原始消息与非零结果。偏差记录有效不代表 PPTX 通过。

严格原生比对按具名单元格检查 Art 批准的表头与数据，允许合法表格内容，同时
继续识别改值、漏格和未绑定文字。偏差验证直接使用 Copy 3.3 的页面层，修复
空 Logic 层造成的异常。

保留 Copy 3.3、Art 2.2 及原生编辑边界。回归覆盖真实表格对象、改值与漏格、
额外文字、命令行诊断、失败及待验状态、工具异常和空 Logic 交接；发布自动化
继续执行完整测试、真实 LibreOffice 检查和压缩包校验，不冒称 PowerPoint/WPS
原生验收。
