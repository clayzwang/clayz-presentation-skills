# Clayz Presentation Skills v0.20.0

Reader understanding now has an executable review path alongside production
fidelity. Supervisor dispatches one fresh reader after Copy and before Art
calibration, and a different fresh reader after final Output, when the host
provides fresh contexts. The instructions explicitly request no inherited
conversation and visible-only inputs. Host dispatch and access limits are
recorded honestly; the local helper does not create an LLM or prove isolation.

`scripts/reader_review.py` prepares packets, freezes actual first understanding,
records later evidence reconciliation and validates review bindings. Copy inputs
exclude research, work notes, relationships and author assessments. Final inputs
use actual page pixels with image metadata removed. Neutral briefs retain the
task and audience without supplying the author's desired answer. First responses
record title reading, retelling, visible evidence, uncertainty and concrete
comprehension findings before production evidence is opened.

Repairs return to the earliest responsible stage. Prior reader findings remain
immutable and linked after a new reading of revised bytes. The existing final
audit collects reader observations, evidence-backed dispositions and host
receipts; current configuration requires both Copy and final review records.
Missing execution and shared-context review remain incomplete evidence. Stale
revisions, altered findings, inherited histories, repeated fresh-reader IDs and
post-Output backfills of pre-Art reviews are rejected as invalid records.

Logic develops substantive answers and concrete comparisons on shared questions.
Copy organizes the reader's questions and supported answers, reads titles as a
sequence and verifies that bodies fulfil their promises. Mechanisms and actual
differences precede writing advice in explanatory/comparative tasks. Titles remain
free to ask, judge or orient; no word quota, mandatory sentence template or
automatic language score is introduced. Fine body units, evidence limits and
Art's composition freedom remain available.

The existing content 3.4, Art 2.3, QA 4.1 and supervision report 3.6 formats remain
readable. Reader review 1.0 is bound through existing audit source records and
collected into the same report. Historical task configurations remain replayable.
Regression tests exercise input exclusion, real image-pixel preservation,
immutable reading, task/revision/timing bindings, honest unavailability, finding
preservation and report collection with explicitly synthetic reader/host data.
These tests do not establish a human-reader effectiveness improvement or a live
host's successful fresh-reader dispatch.

Assets: Cloud Public Light, Local Public Light, Windows CPython 3.12 offline
dependency add-on, and SHA256SUMS.txt. The offline add-on supports Local Light.

## 中文

读者理解审读已接入实际流程。Supervisor 在 Copy 完成、Art 校准前调度一次读者审读，并在 Output 后调度另一个新上下文阅读成品；宿主支持时明确要求不继承制作历史，仅传入可见内容。真实记录宿主调度和访问限制；本地脚本不能创建大模型或证明隔离。

`scripts/reader_review.py` 负责准备输入包、冻结首次理解、记录随后进行的证据核对，并校验交接绑定。Copy 输入排除研究、工作笔记、语义关系说明和作者自评；成品输入采用真实页面像素并清除图片元数据。中性说明保留任务和受众，不提供作者期待的答案。读者先记录标题连读、实际复述、可见依据、疑惑及具体理解缺口，再读取制作证据。

问题交回最早责任阶段修复，修改后重新审读并保留旧记录。现有最终审计收集读者发现、证据处置和宿主回执；新配置要求 Copy 与成品两份记录。未执行及共享上下文审读继续标记证据不足。过期版本、改写原发现、继承历史、复用同一独立读者上下文，以及成品后倒填 Art 前审读，均不能成为有效交接。

Logic 交付主题核心、具体机制及同维度比较。Copy 围绕读者问题与有依据的回答组织讲述，连读标题并核对正文是否兑现承诺；介绍／比较任务先解释机制和差异，再给编写建议。标题仍可提问、判断或定位，不增加字数配额、固定句式或自动语言评分。保留细 body、证据限定和 Art 构图自由。

内容包 3.4、Art 2.3、QA 4.1、审计报告 3.6 继续兼容；读者审读 1.0 经现有审计来源引用进入同一报告，历史任务按其原配置回读。回归验证使用明确标注的合成读者／宿主数据，检查输入排除、实际图片像素保留、首次审读不可覆盖、任务／版本／时序绑定、未执行披露、发现保留和报告收集。这些验证不等于真人理解效果提升，也不代表已完成真实宿主的新上下文调度实验。

发行资产为 Cloud Public Light、Local Public Light、Windows CPython 3.12 离线依赖包及 SHA256SUMS.txt。离线依赖包配合 Local Light 使用。
