# Clayz Presentation Skills v0.19.0

Copy now explicitly hands off body-to-heading ownership, shared support, or the absence of local heading ownership with the passage's page-level purpose. A heading may own both direct body text and child headings; body ownership is allowed at any heading level. Heading relationships are explained from meaning rather than inferred from heading level or array order. These relationships are separate from text and source provenance; they do not prescribe layout or require a body for every heading.

Art records a readable, immutable page-planning artifact before refining native-object specifications. It covers the page message, available content groups and their functions, overall composition and reasons, element strategy, and grounded optional expression additions. Blocks may jointly carry content and direction; geometry, line and type remain freely chosen. Adding no labels or slogans is valid.

The existing report audits planning evidence, content relationships, expression additions, and actual realization separately from Output fidelity. Missing evidence is uncertain; a deferred final render cannot pass planned realization. Original planning bytes and readable planning travel in the report and stage-handoff archive, including portable verification after source removal. Recording timestamps establish recording order, not private reasoning or independent cognitive-process attestation.

New contracts: content package 3.4 and Art plan 2.3; Output QA remains 4.1. Historical 3.3/2.2 and older contracts retain versioned replay. The public cloud and local Light packages include the new guidance, recorder, validators and audit path. Existing A/B artifacts are unchanged; this engine release does not claim a demonstrated visual-quality improvement from a new production experiment.

## 中文

Copy 明确正文归属、共同支撑，或无局部标题归属及其全页用途；同一标题可同时拥有直属正文和子标题，正文可归属任一级标题。标题之间的关系按实际含义交代，不由标题级别或数组顺序推导。关系与文字、来源分别记录，不规定 Art 版式，也不要求每个标题都有正文。

Art 在细化原生对象前保存可读、不可变的逐页艺术规划，说明本页判断、内容组及作用、整体构图及理由、重要元素处理，以及可选新增表达及依据。块可以同时承载内容和方向；形状、线与字保持自由选择，不强制新增标签或 slogan。

既有审计分别检查规划证据、内容关系、新增表达和实际呈现，独立于 Output 执行保真。缺失证据记录为 uncertain，成品渲染延后不能判定呈现通过。真实规划字节和可读规划进入报告及阶段交接包，原路径失效后仍可核验。时间戳证明记录顺序，不证明私有思考过程或独立的认知过程鉴证。

新合同：内容包 3.4、Art 计划 2.3，Output QA 仍为 4.1；历史合同按原版本继续回读。Cloud／Local Light 包包含新指引、记录命令、校验与审计路径。原 A/B 产物不改，本次引擎发布不宣称已经通过新生产试验证明艺术质量提升。
