# Clayz Presentation Skills v0.17.6

Art and Supervisor now review large whitespace against its actual reading purpose. Source and appendix
pages are included; fixed-coordinate gaps need review, and unnecessary filler is not a remedy.

Every tabular presentation requires an integrated native table, including qualitative comparisons.
Shape-built grids and fragmented one-cell tables cannot pass by declaring an approved alternative.
Art may select another presentation medium when it also changes the actual visual form.

Output and Supervisor now inspect fonts inside tables and charts as well as body text. The font audit
covers Latin text, digits, chart titles, axis ticks, legends and generated data labels. Explicit wrong
families fail; missing or unresolved properties remain deferred. The Python adapter writes both Latin
and East Asian chart fields and uses native plot data labels.

Output reserves approximately 10% internal capacity in text boxes, shapes, table cells and chart-label
regions, considering width and height after normal padding. This is not a slide whitespace quota or a
reason to silently shrink text. Inspect internal overflow and collisions, and record PowerPoint/WPS
native checks separately. A single renderer or the reserve target alone cannot establish compatibility.

The release adds synthetic object regressions and retains the repository validation, real LibreOffice
smoke, archive scanning and checksum gates. These checks do not certify subjective design quality or
native PowerPoint/WPS pixels. Public packages include no task-private learning content or user template assets.

## 中文

Art 与 Supervisor 逐页复核大片留白是否承担分组、层级、节奏或聚焦作用，覆盖来源页与附录。
固定坐标留下的空洞须调整或说明实际用途，不用无关内容填满画布。

只要采用表格形式列举，就必须使用完整原生表格，定性比较同样适用。
形状拼表、逐格单单元格表格不能通过登记替代方案放行；Art 可改用其他适合的呈现方式，
但必须改变实际视觉形式，不能只修改媒介名称。

Output 与 Supervisor 检查表格和图表内部字体，覆盖英文、数字、图表标题、轴标签、图例与自动数据标签。
错误显式字体判 fail，缺失字段或继承不明保留 deferred。Python 适配器补齐图表 Latin 与 East Asian 字体字段，
并使用原生绘图区数据标签。

Output 在正常内边距之后，为文本框、形状、表格单元格与图表标签区预留约 10% 内部容量，
兼顾宽度和高度；这不是整页留白配额，也不允许为此擅自缩字。检查文字对容器的溢出及对象间覆盖，
分别记录 PowerPoint/WPS 原生检查。单一渲染器通过或留有余量，均不能代表跨应用兼容通过。

新增合成对象回归，保留仓库完整验证、真实 LibreOffice 冒烟、压缩包扫描与哈希检查。
这些检查不冒称设计质量或 PowerPoint/WPS 像素验收。公共包不含任务私有学习正文或用户模板素材。
