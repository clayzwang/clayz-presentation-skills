# Clayz Presentation Skills v0.5.2

## What this version does

v0.5.2 turns the five-stage presentation workflow into a composable public brain that can run in two environments without forking the method:

- **Cloud Public Light** supplies the public Logic → Copy → Art Direction → Output → Supervisor workflow while relying on inspected ChatGPT host tools as the execution body.
- **Local Public Light** supplies the same public core for local execution. The supported and validated local route in this release is Windows with PowerPoint-compatible tooling.
- **Personal Extension Profile foundation** adds one optional decision before Logic. It can resolve owner-controlled configuration and logical Library mounts without adding a sixth stage or duplicating the retrieval engine.
- **Provider-based retrieval** gives public and owner-private indexes one manifest contract, deterministic snapshot digests, logical `library://` references, and receipt-backed lookup.
- **One resolved runtime** binds the selected configuration and route once so all five stages use the same decisions.

The public repository and release archives contain only the contracts, public catalog, public index, synthetic fixtures, validators, composition scripts, and documentation needed to implement this architecture. They contain no real personal Profile, private Provider or index, organization-specific master, font, presentation, PDF, attachment, case, or prior-learning body.

## Release scope

This is a Windows-first local release plus a host-managed cloud package. v0.5.2 does not publish or claim validation for macOS, Linux, or iOS packages.

Release assets:

- `clayz-presentation-skills-0.5.2-cloud-light.zip`
- `clayz-presentation-skills-0.5.2-local-light.zip`
- `clayz-presentation-skills-0.5.2-offline-windows-py312.zip`
- `SHA256SUMS.txt`

Cloud Public Light needs no offline dependency archive. Local Public Light can install dependencies normally from `requirements.txt`; the Windows offline add-on is optional for CPython 3.12 environments without package-index access.

## Deferred work

Public materials remain organized, searchable, and usable. This release defers the methods for continuous public-material learning, community aggregation, automatic updating, and cross-source fusion. It also defers other operating-system release packages, Task Overlay, remote MCP Providers, and automatic private Library ingestion.

## 这个版本做什么

v0.5.2 把五阶段演示工作流整理成一个可组合的公共“脑”，并让它在两类环境中运行而不分叉方法：

- **Cloud Public Light** 提供公共的 Logic → Copy → Art Direction → Output → Supervisor 流程，由检查后的 ChatGPT 宿主工具充当执行“身体”。
- **Local Public Light** 提供同一公共核心。本版支持并完成验证的本地路线是 Windows 与 PowerPoint 兼容工具链。
- **Personal Extension Profile 基础** 在 Logic 前增加一次可选判断，可以解析所有者控制的配置和逻辑 Library mount，但不增加第六阶段，也不复制检索引擎。
- **Provider 化检索** 让公共与所有者私有索引共用 manifest 合同、确定性 snapshot digest、`library://` 逻辑引用和带回执的检索。
- **唯一解析运行时** 只锁定一次配置和路线，五个阶段共同使用同一组决策。

公共仓库和发布包只包含实现该架构所需的契约、公共目录、公共索引、合成夹具、验证器、组合脚本与文档；不包含真实个人 Profile、私有 Provider 或索引、机构专属母版、字体、演示文稿、PDF、附件、案例或前期学习正文。

## 发布范围

这是“Windows 本地首发 + 宿主管理云端包”。v0.5.2 不发布、也不宣称已验证 macOS、Linux 或 iOS 包。

发布文件：

- `clayz-presentation-skills-0.5.2-cloud-light.zip`
- `clayz-presentation-skills-0.5.2-local-light.zip`
- `clayz-presentation-skills-0.5.2-offline-windows-py312.zip`
- `SHA256SUMS.txt`

Cloud Public Light 不需要离线依赖包。Local Public Light 可以按 `requirements.txt` 正常安装依赖；Windows 离线附加包只供无法访问软件源的 CPython 3.12 环境选用。

## 暂缓工作

公共资料仍然保持可组织、可检索、可使用。本版暂缓的是公共资料持续学习、社区汇聚、自动更新与跨来源融合的方法，同时暂缓其他操作系统发版包、Task Overlay、远程 MCP Provider 和私有 Library 自动摄取。
