# Clayz Presentation Skills v0.7.0

## What this version does

v0.7.0 makes supervision a complete, evidence-bound production record and aligns the ChatGPT upload with the same five-stage Public Core:

- **Accountable supervision** records Supervisor as initiator, mediator, recorder, and final auditor through one canonical lifecycle with concrete, hash-bound evidence.
- **Fresh runtime challenges** bind preflight to the exact task bytes, task root, resolved configuration, one-use issuance and consumption ledgers, and challenge-bound host-tool inventory receipts.
- **One governed ChatGPT Skill** compiles the five responsibility-separated source Skills into one upload unit with one root `SKILL.md`, five internal stage modules, and a validated mount contract.
- **Paired delivery** requires the final PPTX and `ppt-supervision-report.json` to be published together, with `delivery-manifest.json` proving their validated hashes.
- **Observed compatibility** separates authoring/rendering requirements from PowerPoint, WPS, and LibreOffice acceptance. Missing native applications are recorded as `deferred` instead of silently blocking authoring or claiming compatibility.

## Release scope

This release publishes:

- `clayz-presentation-skills-0.7.0-cloud-light.zip`
- `clayz-presentation-skills-0.7.0-local-light.zip`
- `clayz-presentation-skills-0.7.0-offline-windows-py312.zip`
- `SHA256SUMS.txt`

The public source and release archives contain only the shared Public Core, public Provider metadata, generic contracts, validators, bilingual guidance, and synthetic regression fixtures. They contain no organization-specific presentation, private Profile, private Provider manifest or index, owner Library body, brand master, font, attachment, private path, or private source material. The owner-personal ChatGPT composition remains a separate local process and is not a public Release asset.

This version changes public runtime and supervision contracts. Private Profiles and host bindings must explicitly allow core `0.7.0`, then be recomposed and accepted in a fresh host session; the public release never widens private compatibility declarations.

## 这个版本做什么

v0.7.0 把 Supervisor 升级为完整、可归因、证据绑定的生产记录，并让 ChatGPT 上传形态继续复用同一套五阶段 Public Core：

- **完整监督责任**：Supervisor 以发起人、调解人、记录人和最终审核人的身份，按唯一规范生命周期记录具体、可哈希验证的证据。
- **新鲜运行挑战**：预检绑定本次任务原始字节、任务根、resolved config、一次性签发/消费台账，以及绑定同一挑战的宿主工具清单回执。
- **一个受治理的 ChatGPT Skill**：把五个职责隔离的源码 Skill 编译为一个上传单元，保持一个根 `SKILL.md`、五个内部阶段模块和经过验证的挂载契约。
- **成对交付**：最终 PPTX 与 `ppt-supervision-report.json` 必须共同发布，并由 `delivery-manifest.json` 证明两者已经过哈希和语义复核。
- **真实兼容性观察**：制作/渲染硬条件与 PowerPoint、WPS、LibreOffice 的验收分离；原生应用缺失时记录为 `deferred`，不得静默阻断开工或虚构兼容认证。
