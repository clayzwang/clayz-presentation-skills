# Clayz Presentation Skills v0.17.2

Logic now delivers a complete story **and its locked page allocation**. It owns
the thesis, chapters, page claims, page order and body-page count. Copy keeps that
source intact and decides exact wording, trimming, grouping and content tags.
Art Direction continues visual tagging and image drafts; Output implements the
approved design with editable native objects.

Content package **3.1** and story/visual handoff **1.1** remove built-in analytical
routes and the old Logic node/reasoning requirements. Research facts, source and
calculation traceability, definitions, uncertainty, real stage records, calibration
and independent audit remain. Historical 2.4/3.0 artifacts retain version-specific
replay; old contracts do not become requirements for new work.

Default cover and closing pages retain editable text, with relevant illustrative
images when useful and assets sized/compressed for their placement and budget.
No proactive speaker-note or appendix generation. Historical or requested notes
remain readable. The pinned STKAITI.TTF Version 1.02 identity is included; the
owner-private font binary is not redistributed.

Validation includes 3.1 ownership, evidence, Copy/Art tagging and real CLI
calibration → report assembly → publication → verified handoff, alongside 3.0
compatibility and the repository suite. These are synthetic integrity regressions,
not claims of native PowerPoint/WPS visual acceptance.

Published packages: Cloud Public Light, Local Public Light, the Windows CPython
3.12 offline dependency add-on, and SHA256SUMS.txt. Actual generation/rendering
capabilities depend on the host.

## 中文

Logic 现在同时交付**完整 story 和锁定的页面安排**：总论点、章节、逐页主张、页序和正文页数均由 Logic 决定。Copy 保留原始 story 和 logic_layer，自主决定具体文字、剪裁、内容分组及打标；Art Direction 继续视觉打标和图片稿，Output 用原生可编辑对象实施。

新内容包 **3.1**、交接扩展 **1.1** 删除工具内置分析套路及旧 Logic 节点／推理要求。保留研究事实、来源与计算可追溯性、口径、不确定性、实际阶段工作记录、校准和独立审计。历史 2.4／3.0 按原版本兼容读取，不把旧约束重新施加给新任务。

默认生成封面和尾页，文字原生可编辑，适合时采用形象配图并按显示尺寸压缩控制体积。不主动生成演讲备注或附录，历史或用户要求的备注仍可读取。同步纳入 STKAITI.TTF Version 1.02 文件身份锁；用户私有字体二进制不进入公开仓库或发布资产。

验证覆盖 3.1 责任边界、证据、Copy／Art 打标，以及实际 CLI 的校准、报告组装、发布和交付回验，并保留 3.0 兼容和全仓检查。回归使用合成样例，不代表已完成 PowerPoint／WPS 原生视觉验收。
