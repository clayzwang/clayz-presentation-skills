# Clayz Presentation Skills v0.6.0

## What this version does

v0.6.0 makes resource discovery and Index evidence mandatory parts of presentation production instead of optional background guidance:

- **Inventory before authoring** makes Supervisor scan the complete mounted plugin runtime, task inputs, owner Library, public Index, brand assets, host capabilities, and fonts before Logic starts. It tells the user what was found, what will be used, what is unavailable, and which production and rendering route is locked.
- **First-class Index execution** locks one Provider snapshot for the task, materializes owner learning only from a task-supplied manifest, and requires finalized Retrieval Receipts from Logic, Copy, Art Direction, Output, and Supervisor.
- **Deterministic content gates** reject mechanical wording and grammar repetition, generic first visuals, unjustified silhouette or structure reuse, shape-only pseudo-charts, missing connectors, and duplicated slide-agnostic supervision text.
- **Complete-plugin mount validation** prevents an isolated Skill folder from silently running without the shared contracts, validators, runtime policy, and bilingual references it depends on.

These controls address presentation failures such as repetitive expression, weak hierarchy, tiny type, misalignment, arbitrary connectors, and diagram structures that are coupled directly to text boxes without semantic or technical checks.

## Release scope

This release continues to publish one Cloud Public Light package, one Windows-validated Local Public Light package, and one optional Windows CPython 3.12 offline dependency add-on:

- `clayz-presentation-skills-0.6.0-cloud-light.zip`
- `clayz-presentation-skills-0.6.0-local-light.zip`
- `clayz-presentation-skills-0.6.0-offline-windows-py312.zip`
- `SHA256SUMS.txt`

The public source and release archives contain generic contracts, public Index records, validators, bilingual guidance, and synthetic regression fixtures only. They contain no organization-specific presentation, brand asset, private Provider, private index, owner file inventory, private path, font, attachment, or source material.

Owner-private Profiles remain fail-closed. A Profile that explicitly capped compatibility below `0.6.0` must be reviewed and given an appropriate `maximum_core_version_exclusive` before it can run on this release; the public package never widens a private compatibility declaration silently.

## 这个版本做什么

v0.6.0 把“资源发现”和“Index 执行证据”从可选背景知识升级为演示文稿生产的强制步骤：

- **开工前先盘点**：Supervisor 在 Logic 前完整扫描已挂载插件运行时、任务输入、所有者 Library、公共 Index、品牌资产、主机能力和字体；先向用户说明发现了什么、将使用什么、哪些不可用，以及锁定哪条制作与渲染路线。
- **Index 成为一等执行依赖**：整项任务锁定一份 Provider 快照；所有者学习资料只能从任务级清单物化；Logic、Copy、Art Direction、Output 和 Supervisor 都必须提交最终 Retrieval Receipt。
- **确定性内容门禁**：拦截机械重复的话术和语法、空泛首要视觉、无理由复用的页面轮廓与结构、以形状冒充图表、缺失连接线，以及跨页复制的泛化监督文字。
- **完整插件挂载校验**：防止单独拿到一个 Skill 文件夹后，在缺少共享契约、验证器、运行时策略和双语参考的情况下静默降级执行。

这些控制直接针对表达高度重复、层级失效、字号过小、对象不对齐、乱连线，以及框线与文字框直接耦合却缺乏语义和技术检查等问题。

## 发布范围

本版继续发布 Cloud Public Light、经过 Windows 验证的 Local Public Light，以及可选的 Windows CPython 3.12 离线依赖包：

- `clayz-presentation-skills-0.6.0-cloud-light.zip`
- `clayz-presentation-skills-0.6.0-local-light.zip`
- `clayz-presentation-skills-0.6.0-offline-windows-py312.zip`

公共源码和发布包只包含通用契约、公共 Index 记录、验证器、双语方法说明与合成回归样例；不包含任何机构专属演示文稿、品牌资产、私有 Provider、私有索引、所有者文件清单、私有路径、字体、附件或源材料。

所有者私有 Profile 继续采用失败关闭策略。若某份 Profile 明确把兼容上限限定在 `0.6.0` 以下，必须经过审阅并适当提高 `maximum_core_version_exclusive` 后才能用于本版；公共包不会静默放宽私有兼容声明。
