# 0.17.5

STKaiti is not bundled because redistribution authorization is unavailable. Install it separately from a licensed source when required by a task; report missing fonts and substitutions explicitly. Every optional bundled font still requires source, authorization and hash verification.

STKaiti 未获再分发授权，因此不随包发布。任务需要时须从合法来源单独安装，并明确披露缺字和替代渲染；任何可选随包字体仍须核验来源、授权及哈希。

Changes: OPC metadata namespace fix; suppress inherited shape effects; exact native table-cell/multiline comparison; Art-owned font size and repetition judgment; runtime failure/timeout evidence; 20 MB ordinary PPTX publication boundary; external hash-bound report evidence with lossless reconstruction; font manifest/install helper and pinned Python dependency environment.

变更：元数据命名空间修复、消除继承阴影、原生表格单元格及多段文案精确比较；字号和构图雷同交由 Art 判断；运行失败及超时证据；普通 PPTX 交付控制在 20 MB 以下；报告正文与 hash 绑定的外置证据及无损还原；字体清单、安装工具与固定 Python 依赖。

Validation: run `python -B scripts/validate_all.py`. GitHub CI adds actual LibreOffice import/export with integrated tables, multiline text and signed negative chart labels. This does not establish pixel geometry or PowerPoint/WPS editing acceptance. Art must still inspect and repair actual grouping, space allocation and repeated composition; removing numeric rules alone does not certify design quality.

验证：全量仓库检查及 GitHub CI 的真实 LibreOffice 导入导出；不声称完成 PowerPoint/WPS 原生编辑或像素几何验收。信息分组、空间分配及构图重复仍需 Art 对实际页面审查和整改。
