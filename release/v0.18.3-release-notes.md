# Clayz Presentation Skills v0.18.3

Art now reads bilingual, reader-centered composition guidance before designing.
It starts with what the reader needs to notice and understand, uses space to
express supported information relationships, and allocates attention according
to the role of the evidence and its conditions. Heading counts and shared
drawing defaults do not determine the composition.

Art inspects actual thumbnails, full-size drafts and the page sequence for
reading effort, useful repetition, rhythm and visual fatigue. When distinct
communication tasks receive the same scanning pattern and emphasis, Art
revises the affected designs and inspects the sequence again. Consistent or
tidy containers and written justifications alone do not establish that the
reading experience works. There is no fixed layout quota, automatic aesthetic
score or new approval form.

Art no longer searches for, downloads or loads learning packages by default,
including available local copies. It uses them only when the user explicitly
requests them. Original design and relevant references remain available.

Copy 3.3, Art 2.2, the existing handoff, native editing boundaries and audit
contracts remain unchanged. The new guidance is included in both public Light
targets and the localized standalone Skill composer. A synthetic packaging
regression checks that the delivered Art module can reach the selected English
or Chinese guidance and that its bytes match the source. This release changes
design instructions; it does not claim that guidance alone proves improved
visual quality in a new presentation.

## 中文

Art 在设计前阅读中英文排版启示，从读者需要看见和理解什么出发，用空间表达
有内容依据的信息关系，并根据证据和必要条件的作用分配注意力。标题数量和
共用绘图代码的默认位置不能代替构图判断。

Art 检查真实缩略图、全尺寸图稿及连续页的阅读负担、有用重复、节奏和审美
疲劳。不同沟通任务若被处理成相同的扫描方式与强调，须修改相关设计并重新
观察序列。容器整齐、文字齐全及书面理由不足以证明阅读体验成立。不增加
固定版式配额、自动审美评分或审批表。

Art 默认不再搜索、下载或加载学习包，包括已存在的本地副本；仅在用户明确
要求时使用。继续允许原创设计和有助解决具体问题的参考资料。

保留 Copy 3.3、Art 2.2、现有交接、原生编辑边界和审计合同。两个公共 Light
目标与单一 Skill 的本地化 composer 都携带新指引；合成打包回归检查实际交付
Art 模块能够访问所选中英文指引，且正文与源码一致。本版更新设计指令，实际
成稿的视觉质量仍需通过制稿与看图检验。
