# Clayz Presentation Skills v0.9.0 candidate

## What this candidate changes

- Converts explicit user requirements into one task acceptance contract that survives every governed handoff.
- Adds relevance-ranked, thresholded, bounded retrieval with concrete adoption targets instead of ceremonial source consumption.
- Makes the supervision report self-contained with immutable Logic, Copy, and Art Direction decision snapshots, requirement traceability, retrieval-quality evidence, and generation-efficiency evidence.
- Adds a deterministic PPTX font-name audit so deferred native rendering cannot hide a wrong written East Asian family.
- Removes automatic GitHub Release creation. A protected ChatGPT candidate upload, version/private-learning acceptance receipt, and explicit user approval are now hard prerequisites.

This file describes a local-build candidate. Tagging and publication remain disabled until the exact Personal candidate is uploaded to ChatGPT, accepted in a fresh conversation, and bound to a private release receipt for the final commit.
