# Clayz Presentation Skills v0.17.3

Remove the remaining prescribed three-question Logic route and mandatory single-sentence, single-line Storyline instructions. Storyline is optional by default: Copy decides wording and intentional breaks, Art Direction decides layout, and only explicit requirements of a user-selected master constrain placement or role. Package 3.1 no longer requires the single-line Storyline QA check; supplied historical checks remain readable and older contract validation is unchanged.

Source citations go in task records; speaker notes are written only when explicitly requested. Complete Logic story and locked page allocation, Copy/Art tagging, evidence checks and work reports remain intact. No private brand master or font binary is included.

Validation covers optional Storyline and intentional breaks, real 3.1 CLI handoff and historical compatibility, plus the repository suite and release archive checks. Synthetic integrity tests do not constitute native PowerPoint/WPS visual acceptance.
