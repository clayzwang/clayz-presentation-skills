# Clayz Presentation Skills v0.16.0

## What this version changes

Since v0.8.0, the Public Core has grown from startup/version-bound learning
checks into one enablement-oriented workflow. The five production stages still
own their responsibilities, while each task follows one resolved path:
defaults, saved personal settings, and task overrides. Public-first execution
remains usable when optional sources are not selected; selected sources and
resources stay bound to the same task configuration through every handoff.

- **Three Supervisor calibrations:** the Supervisor records the Logic-to-Copy,
  Copy-to-Art Direction, and Art Direction-to-Output calibrations as separate,
  hash-bound handoff evidence. Each disposition records whether the downstream
  stage accepted, partially accepted, or declined the upstream guidance and why.
  The Supervisor coordinates these decisions without silently rewriting a stage's
  owned work.
- **Independent post-Output audit:** `independent-audit/1.0` reads the immutable
  request, acceptance rules, Supervisor commitments, and the actual PPTX/object/
  render evidence. It reports findings, coverage, and uncertainty; Supervisor
  preserves those observations and decides the release disposition.
- **Durable work report 3.6:** the report records task requirements, research
  facts, evidence, definitions, assumptions, unknowns, storyline, copy, design
  intent, stage notes, calibration dispositions, Auditor observations, release
  limitations, and observed improvements in one source-bound JSON record. A
  deterministic `work-report.md` companion is derived from that record.
- **Exact delivery checks:** the final PPTX is reopened as OOXML in slide order,
  including page text, notes, slide-owned object counts, and separate master and
  unused-media evidence. The final PPTX, `ppt-supervision-report.json`,
  `work-report.md`, and `delivery-manifest.json` are checked for exact paths,
  hashes, title, slide count, and object statistics before handoff.

## Evidence and limits

The local 331-test run passed. The user supplied the generated v0.16.0 output
and judged the improvement worth retaining. The available audit evidence is a
simplified `delivery-audit/1.0` report, so this release does not claim strict
end-to-end acceptance on a ChatGPT host or assert an exact ChatGPT candidate
commit acceptance receipt. Native rendering and target-application checks remain
reported with their actual `pass`, `fail`, `deferred`, or `not-run` coverage.

This release keeps the public boundary: source packages contain generic
contracts, validators, bilingual guidance, and synthetic regression material.
User-supplied masters, attachments, fonts, generated presentations, and other
host-specific material remain outside the public source and release archives.

## 中文说明

自 v0.8.0 以来，Public Core 已从启动时的版本／学习校验，发展为一套
以启用任务为中心的统一流程。五个生产阶段仍各自负责本阶段工作，每个任务
都沿着同一条已解析路径执行：默认配置、已保存的个人设置、任务覆盖。未选择
可选资料时仍可使用公共优先路线；任务选中的资料和资源会在全部交接中绑定到
同一份任务配置。

- **Supervisor 三轮校准：** Supervisor 将 Logic→Copy、Copy→Art Direction、
  Art Direction→Output 三次校准分别记录为带哈希的交接证据。每次记录下游
  阶段接受、部分接受或拒绝上游指导的处置及原因；Supervisor 负责协调，不会
  静默改写阶段所有者的工作。
- **独立 Output 后审计：** `independent-audit/1.0` 读取不可变的用户请求、
  验收规则、Supervisor 承诺以及实际 PPTX／对象／渲染证据，报告发现、覆盖范围
  和不确定性。Supervisor 保留这些观察，并决定发布处置。
- **持久化 work report 3.6：** 一份受源绑定的 JSON 工作记录统一保存任务要求、
  研究事实、证据、定义、假设、未知项、Storyline、Copy、设计意图、阶段 notes、
  校准处置、Auditor 观察、发布限制和已观察到的改进，并确定性派生
  `work-report.md`。
- **准确交付检查：** 按真实幻灯片顺序重新打开最终 PPTX 的 OOXML，检查页面文字、
  notes、每页自有对象数量，以及独立的 master／未使用媒体证据；交付前核验最终
  PPTX、`ppt-supervision-report.json`、`work-report.md` 与 `delivery-manifest.json`
  的准确路径、哈希、标题、页数和对象统计。

## 证据与限制

本地 331 项测试已通过。用户提供了 v0.16.0 生成物，并认为这次改进值得保留。
现有审计是简化的 `delivery-audit/1.0` 报告，因此本版不宣称真实 ChatGPT 宿主
严格全链路验收成功，也不伪造精确 ChatGPT 候选提交验收回执。原生渲染和目标应用
检查继续按实际覆盖情况记录为 `pass`、`fail`、`deferred` 或 `not-run`。

本版继续保持公共边界：源码只提供通用合同、验证器、双语说明和合成回归材料。用户
提供的母版、附件、字体、生成演示文稿及其他宿主专属资料均留在公共源码和 Release
包之外。
