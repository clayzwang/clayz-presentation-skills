# Clayz Presentation Skills v0.16.0

A reusable presentation workflow for language models and agent environments. This release improves how requirements, content, design decisions, and audit evidence stay connected from the initial brief to final delivery.

## Highlights

- **Unified requirements:** combine defaults, saved settings, and task-specific instructions while preserving their priority throughout production.
- **Supervisor calibration:** review the Logic → Copy, Copy → Art Direction, and Art Direction → Output handoffs, with recorded feedback and downstream decisions.
- **Independent audit:** inspect the final presentation against the task requirements, report findings and coverage limits, and return the results to Supervisor for the delivery decision.
- **Detailed work reports:** retain sources, assumptions, storyline, copy, design intent, stage notes, and audit findings in a source-bound JSON report, with a readable Markdown companion.
- **Reliable delivery checks:** verify the presentation, reports, and manifest against the same task; inspect slide order, page text, notes, native objects, and file hashes.
- **Explicit limitations:** record missing resources, deferred checks, and quality issues accurately, allowing useful work to be delivered under the task's delivery policy.

## Packages

- **Cloud Public Light:** shared skills and contracts for hosted agent environments.
- **Local Public Light:** the public core with local execution support.
- **Windows offline add-on:** dependencies for Windows x86-64 and CPython 3.12.
- **SHA256SUMS.txt:** checksums for the release archives.

The workflow can be used by different models through compatible skill and tool integrations. Available generation and rendering capabilities depend on the host environment.

## 中文说明

Clayz Presentation Skills 是供不同大模型和 Agent 环境使用的演示文稿工作流。本版加强了从任务要求、内容与设计，到审计和最终交付之间的连续性。

- **统一任务要求：** 按默认配置、已保存设置、当前任务指令的优先级执行，并在制作过程中持续保留要求。
- **Supervisor 三轮校准：** 在 Logic → Copy、Copy → Art Direction、Art Direction → Output 的交接处记录评价、调整意见及下游处理结果。
- **独立审计：** 对照任务要求检查最终演示文稿，记录发现与检查范围，再由 Supervisor 决定交付。
- **详细工作报告：** 用关联原始产物的 JSON 保存来源、假设、故事线、文案、设计意图、阶段笔记和审计发现，并生成便于阅读的 Markdown 报告。
- **准确交付核对：** 确认演示文稿、报告和清单属于同一任务，核对实际页序、文字、备注、原生对象及文件哈希。
- **如实记录限制：** 对资源缺失、待执行检查和质量不足作出明确披露，按任务交付政策保留可用成果。

### 发布包

- **Cloud Public Light：** 面向托管 Agent 环境的通用技能与合同。
- **Local Public Light：** 包含本地执行支持的公共核心。
- **Windows 离线附加包：** 适用于 Windows x86-64 与 CPython 3.12 的依赖。
- **SHA256SUMS.txt：** 发布压缩包的校验清单。

不同模型可通过兼容的技能与工具接口使用本工作流；实际生成和渲染能力取决于所在的宿主环境。
