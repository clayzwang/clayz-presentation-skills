# Clayz Presentation Skills v0.19.1

Copy now owns explicit editorial reasoning for reader understanding. It develops and retains the actual reader-facing explanation before editing into titles, headings, body and annotations. The existing meaning review compares Logic findings with that explanation and the final wording, citing concrete actors, mechanisms, discriminating facts and any consequential omissions or moves.

Body is resolved as finely as fluent language and logical continuity permit. Multiple body units may belong to one heading. Existing relationship purposes explain each passage's contribution and material dependencies; necessary subjects, connectors, conditions and qualifications remain intact. Art decides which passages share paragraphs, objects or visual groups and which merit separate treatment or emphasis.

Structural validation and professional content reading retain distinct outcomes. A source ID, schema pass or empty issue list cannot automatically become a content-reading pass. Missing reading evidence remains deferred or not recorded. Supervisor compares the research, explanation, fine text and actual presentation through existing records; this release adds no word quota, unit quota, keyword-based fluency score or new approval form.

The root instruction, Copy references, public methods Index and packaged Index descriptions are aligned. Content package 3.4, Art plan 2.3 and Output QA 4.1 remain unchanged; historical artifacts retain their versioned replay. Text-only diagnostic work checked a complete explanation decomposed into 15 body units with exact reconstruction and specific meaning-review observations. It does not establish a rendered-page or visual-quality improvement.

Release assets: Cloud Public Light, Local Public Light, Windows CPython 3.12 offline dependency add-on and SHA256SUMS.txt. The offline add-on supports Local Light and is not a Cloud Light dependency.

## 中文

Copy 明确承担面向读者的编辑判断：先形成并保留实际讲述稿，再组织标题、正文及注释。沿用现有语义复核，将 Logic 发现、完整讲述和最终文字逐项核对，记录具体对象、机制、具有区分价值的事实，以及重要删减或迁移的真实去向。

body 在通顺和逻辑完整的前提下尽可能拆细，同一标题可以拥有多个正文单元。现有关系 purpose 说明各段贡献及重要依赖，保留必要主语、衔接词、条件与限定。Art 决定哪些段落组合成一段、一个对象或内容组，哪些需要分开呈现或突出。

结构校验与内容审读分别判断。来源 ID、结构通过或问题列表为空，不能自动变成内容审读通过；没有实际阅读的检查保留 deferred／not-recorded。Supervisor 通过现有记录比较研究、讲述、细分文字及真实呈现，不增加字数配额、单元数量目标、关键词语言评分或审批表。

同步根指令、Copy 参考、公开索引与打包后的检索描述。内容包 3.4、Art 计划 2.3、Output QA 4.1 保持不变，历史材料按原版本回读。文本级样例将完整讲述拆为15个 body，逐字重组一致，并保留具体语义审读观察；该验证不等于已经证明成品排版或视觉质量提升。
