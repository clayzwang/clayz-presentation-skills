# Clayz Presentation Skills v0.8.0

## What this version changes

v0.8.0 makes startup identity and owner-private learning observable instead of implicit:

- Every presentation run checks the official GitHub Latest Release and prints the mounted Public Core, configuration, runtime, five-stage contract, and Personal Runtime/Profile versions before Logic.
- Runtime preflight contract 1.3 rejects a missing, stale, older, mismatched, or incomplete component-version report.
- Personal Extension Runtime contract 1.1 adds a fail-closed, version-bound private-learning policy.
- The first owner-personal run of each Public Core version hashes the admitted private source bytes, builds a persistent private Index, executes retrieval probes for knowledge, templates, standards, and methods, and emits a separate JSON/Markdown learning audit.
- Later tasks verify and reuse that same audit and Index. Source changes under the same version fail with `PRIVATE_LEARNING_SOURCE_DRIFT` instead of silently relearning.

“Learning” means persistent, retrieval-verified private indexing. It does not change model weights, weaken human admission, or publish owner material.

## Upgrade notes

- Owner-personal hosts must supply a persistent state root outside the task sandbox.
- Owner-learning manifests must classify every source with `knowledge_kinds` and cover `private-knowledge`, `template`, `standard`, and `method` in aggregate.
- ChatGPT Personal packages must be recomposed from a compatible external Profile and current Provider manifests. No private source body or private Index is bundled in the public release.

## Release scope

This release publishes Cloud Public Light, Local Public Light, the Windows CPython 3.12 offline add-on, and checksums. The owner-personal ChatGPT Skill remains a separate local composition generated from the released Public Core and repository-external private control plane.

## 中文说明

v0.8.0 把“正在运行什么版本、是否真正学习过私人资料”从隐含假设改成可验证事实：

- 每次任务在 Logic 前访问官方 Latest Release，并打印公共核心、配置、运行时、五阶段合同与 Personal Runtime/Profile 版本表；
- 运行时预检合同升级为 1.3，缺失、过期、落后或漂移的组件报告直接失败；
- Personal Runtime 合同升级为 1.1，新增按 Public Core 版本绑定的一次性私有学习政策；
- 某版本首次运行时真实哈希已准入的知识、模板、规范和方法，构建持久私有索引、执行检索探针，并生成独立 JSON/Markdown 学习审计；
- 后续任务只验哈希复用，同版本来源变化不会静默覆盖首次学习记录。

这里的“学习”是持久化、可检索、可审计的私有索引学习，不是修改模型权重，也不会把私人正文打进公共包。
