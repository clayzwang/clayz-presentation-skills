# Clayz Presentation Skills v0.20.3

Art now follows an explicit design dependency: read the complete Copy handoff, prepare page semantics, decide attention, realize expression/composition/visual language, then inspect drafts and revise. Text roles, argument responsibilities, entity/category ownership and visual responsibilities are separate dimensions. A04/A05 establish concrete object and group meanings; A06 uses them to allocate attention; A07–A09 translate those decisions into design, including color. Knowledge is consulted where a decision is made and recorded through existing planning fields.

The Art learning package remains unchanged from v0.20.2. This release changes workflow instructions and adds bilingual process guidance with a synthetic example; it does not add knowledge codes, schemas, agents or approval gates. Original Copy and Art revisions remain traceable. Early title/content reader checks use text; only final reader review requires the rendered artifact. Art's own draft inspection remains part of design work.

Validation covers repository checks, runtime smoke and release bundle integrity. These checks do not establish a measured improvement in aesthetic quality or reader understanding; that requires evaluation on new presentation work.
