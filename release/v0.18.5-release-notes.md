# Clayz Presentation Skills v0.18.5

Art now explicitly treats the whole composition as visual expression alongside words. The model chooses spatial, pictorial and typographic means for the content, then inspects whether the actual arrangement communicates the intended relationships and emphasis. Frames, blocks and background depth are examples, not mandatory objects, a finite menu or a layout recipe. Restrained typographic pages remain valid when they serve the reader.

This release includes the pending visual-balance improvements: judge color, filled area, position, grouping and text density together; revise misplaced weight while retaining useful compositional contrast. Making every background pale can erase hierarchy just as indiscriminate heavy fills can distort it. Inspect actual color thumbnails, full-size drafts and the deck sequence.

The new guidance uses existing Art records and contracts. Copy text, paragraph segmentation and heading rules remain unchanged. No learning package, fixed layout rotation, color quota, symmetry rule or automatic aesthetic score is introduced.

Version 0.18.4 preparation was superseded before publication by the user's explicit request for 0.18.5. This release carries both sets of Art improvements; the previous published version is 0.18.3.

## 中文

Art 明确让整体构图与文字共同参与表达。模型根据具体内容自由选择空间、图像、形状或文字构成等手法，再检查实际页面能否传达应有关系与重点。框、块、背景深浅只是举例，不是必用对象、封闭菜单或版式配方；适合读者的克制文字构成同样成立。

本版同时包含待发布的平衡改进：综合判断颜色、填色面积、位置、分组和文字密度，调整不当重量，同时保留有效构图对比。不能把“平衡”简化为全部变浅，也不能用无差别重色块压平内容关系。检查实际彩色缩略图、全尺寸页面和连续页。

继续使用现有 Art 记录与合同；Copy 文案、分段和标题规则不改，不引入学习包、固定页型轮换、颜色配额、对称规则或审美自动评分。

v0.18.4 尚未发布时，用户明确改为开发并发布 v0.18.5，因此两项 Art 改进合并在本版交付；此前正式版本为 v0.18.3。
