# Clayz Presentation Skills v0.7.1

## What this version fixes

v0.7.1 is a focused font-identity and public-boundary patch:

- **Canonical font identities** model a requested family, equivalent installed-name aliases, and one explicit PPTX family as a single identity.
- **Alias-safe fallback stacks** reject aliases such as `STKaiti` when they are incorrectly repeated as another fallback after `华文楷体`.
- **Consistent PowerPoint fields** require the selected `pptx_family` in both Latin and East Asian text fields and report requested, matched, and written names separately.
- **Resolved-config validation** blocks an invalid Personal Extension configuration before a ChatGPT standalone Skill can be composed.
- **Public fixture hygiene** replaces a private-looking logical Library namespace in synthetic resource-inventory fixtures with `library://example-presentation/` and refreshes their bound hashes.

## Release scope

This release publishes:

- `clayz-presentation-skills-0.7.1-cloud-light.zip`
- `clayz-presentation-skills-0.7.1-local-light.zip`
- `clayz-presentation-skills-0.7.1-offline-windows-py312.zip`
- `SHA256SUMS.txt`

The public source and release archives contain only the shared Public Core, public Provider metadata, generic contracts, validators, bilingual guidance, and synthetic regression fixtures. They contain no private Profile, private Provider manifest or index, owner Library body, organization master, font binary, attachment, native private path, or private source material. Owner-personal ChatGPT composition remains a separate local process and is not a public Release asset.

The public default keeps `font_validation` disabled until an explicit configuration supplies a governed identity. Private Profiles that use the new policy must declare one canonical family, its true aliases, and one PPTX family; the public release does not widen private compatibility or bundle the font itself.

## 这个版本修复什么

v0.7.1 是一次聚焦字体身份和公共边界的补丁发布：

- **规范字体身份**：把请求字体名、等价安装别名和唯一 PPTX 写入字体建模为同一个身份。
- **别名安全的回退栈**：当 `STKaiti` 被错误地重复放在 `华文楷体` 后面作为另一层 fallback 时，验证器会直接拒绝。
- **一致的 PowerPoint 字段**：Latin 与 East Asian 文本字段必须写入同一个 `pptx_family`，并分别记录请求名、实际命中名和最终写入名。
- **resolved config 校验**：ChatGPT 单 Skill 组合前先验证最终 Personal Extension 配置，错误配置不得进入 ZIP。
- **公共样例清洁**：把合成资源盘点样例中的私人式逻辑 Library 命名替换为 `library://example-presentation/`，并同步刷新其绑定哈希。
