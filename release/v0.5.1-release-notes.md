# Clayz Presentation Skills v0.5.1

## What changed

- Added a host-model-independent PowerPoint authoring baseline using `python-pptx`.
- Added one-shot capability preflight, A–D interaction profiles, fixed route locking, bounded tool calls, and one targeted repair cycle.
- Added one light plugin archive plus separate Windows, macOS, and Linux offline dependency archives.
- Kept PDF/Poppler lazy: ordinary PPTX authoring does not require PDF conversion tooling.
- Added archive-level checks that exclude presentation cases, showcase media, private corporate material, fonts, caches, and unreviewed binaries from the plugin release.

## Which file should I download?

The light archive is the plugin itself and is always required:

- `clayz-presentation-skills-0.5.1-light.zip`

If Python dependencies are already installed, or the machine can access PyPI, no offline archive is needed. Install missing dependencies from the extracted light archive with:

```bash
python -m pip install -r requirements.txt
```

For a machine without package-index access, download the light archive **and** exactly one matching offline add-on:

- Windows x86-64 + CPython 3.12: `clayz-presentation-skills-0.5.1-offline-windows-py312.zip`
- macOS arm64/x86-64 + CPython 3.12: `clayz-presentation-skills-0.5.1-offline-macos-py312.zip`
- manylinux 2.28 x86-64/aarch64 + CPython 3.12: `clayz-presentation-skills-0.5.1-offline-linux-py312.zip`

Extract the matching offline add-on and run:

```bash
python install_offline_dependencies.py
```

The offline installer uses only bundled, hash-locked wheels and does not contact a package index. The offline add-on is not a standalone plugin and cannot replace the light archive.

Python, PowerPoint, WPS, LibreOffice, and Poppler are not redistributed. Rendering capability is selected from software already present on the machine.

## 中文用法说明

轻量主包是插件本体，**始终需要下载**：

- `clayz-presentation-skills-0.5.1-light.zip`

如果电脑已经装好 Pillow、`python-pptx`、PyYAML 等依赖，或者可以联网访问 PyPI，只使用轻量主包即可。缺少依赖时，在解压后的主包目录运行：

```bash
python -m pip install -r requirements.txt
```

如果电脑不能联网，需要同时下载轻量主包和一个与操作系统匹配的离线附加包：

- Windows x86-64、CPython 3.12：`clayz-presentation-skills-0.5.1-offline-windows-py312.zip`
- macOS arm64/x86-64、CPython 3.12：`clayz-presentation-skills-0.5.1-offline-macos-py312.zip`
- manylinux 2.28 x86-64/aarch64、CPython 3.12：`clayz-presentation-skills-0.5.1-offline-linux-py312.zip`

解压对应离线包后运行：

```bash
python install_offline_dependencies.py
```

离线包只负责安装经过哈希锁定的 Python wheel，不是独立插件，也不能代替轻量主包。Python、PowerPoint、WPS、LibreOffice 和 Poppler 仍由使用者的电脑提供。

使用 `SHA256SUMS.txt` 校验四个压缩包后再安装。
