# Clayz Presentation Skills v0.18.0

Copy now hands clean text to Art: title (main Storyline), subtitle (secondary
Storyline), headings at the needed levels, body and annotations. Every category
is optional; levels may be skipped and no heading/body pairing is required.
Copy can reorganize the complete story while preserving its supported meaning.
Source provenance remains separate from the text document.

New content package 3.3, Art plan 2.1 and Output QA 4.1 remove Copy layout kinds,
separate-render commands, merge bans, sibling-style requirements and binding of
editorial order to visual reading order. Art chooses the presentation. Multiple
Copy IDs can occupy one editable text object or native cell with disjoint text
ranges; native PPTX comparison still detects missing, changed and extra text.

Light ships no Art layout collection or design/layout index. Art prefers
relevant learning-package indexes and actual content when available, otherwise
seeks useful web references and uses original model design. No-match or
unavailable optional references does not restrict creativity to a catalog.
Learning-package authoring and packaging are outside this release's scope.

Supervisor retains content/meaning, readability and implementation review
without inheriting removed rules or adding aesthetic quotas. Source bindings,
editable delivery, native table/chart reliability, font auditing, internal
capacity and actual render coverage remain. Historical contracts retain their
versioned replay checks. Synthetic regressions establish contract and native
object behavior; they do not certify subjective design quality or native
PowerPoint/WPS pixels.

## 中文

Copy 现在只交干净文字：标题（主 Storyline）、副标题（次级 Storyline）、
各级标题、正文和注释。每类都可没有，层级可以跳级，标题下不必有正文。
Copy 可以调整和重组完整故事，保留有证据的真实含义；来源追溯单独保留。

内容包 3.3、Art 计划 2.1 和 QA 4.1 清理 Copy 版式类型、强制单独渲染、
禁止合并、同级同样式及文字顺序绑定视觉顺序。Art 自主决定呈现。
多个文案 ID 可以通过不相交字符区间共用一个可编辑文本对象或原生单元格；
实际 PPTX 比对仍检查遗漏、改字和额外文字。

轻量包不带 Art 版式库、设计索引或布局索引。有学习包时，优先查相关索引和实际内容；
没有时主动从网上找适用参考并依靠大模型自主设计。无匹配或可选参考不可用时，
不会把创造力锁回预置目录。学习包如何编写和包装不在本次版本范围内。

Supervisor 保留内容、含义、可读性和执行偏差检查，不继承已删除规则，不增加审美配额。
来源绑定、可编辑交付、原生表格／图表、字体、内部容量和真实渲染覆盖保持有效。
旧合同只按原版本回读。合成回归验证契约和原生对象行为，不冒称设计质量或
PowerPoint／WPS 原生像素验收。
