# Clayz Presentation Skills v0.18.1

Art now explicitly owns native editing boundaries. Art plan 2.2 gives every
declared physical object a unique native_name and render_separately:true.
Optional native_group_path retains separate editable children that move together.
Art chooses the boundaries from the intended selection, movement, width and
formatting operations; existing purpose/work notes record consequential choices.

Copy remains clean text under package 3.3. Several Copy paragraphs may share
one explicitly declared Art text object. No paragraph-level separation, peer
style parity or Copy-to-visual-order rule returns.

Output must preserve Art's named objects, native types and exact grouping.
Merging, splitting, regrouping or flattening changes the approved editing
behavior and returns to Art. Native PPTX comparison and Output QA inspect real
objects and groups in addition to text ranges. Supervisor uses the existing
native_editability observation for editing fidelity and the suitability of
Art's boundaries, without additional approval forms or aesthetic quotas.

Historical Art plan 2.1 remains versioned replay support. Regressions exercise
shared text, separate objects, native groups, unapproved merges/regrouping and
flattened substitutes. Release CI extends actual LibreOffice reopening/render
smoke to separate editable children inside a native group; this does not claim
PowerPoint/WPS native application acceptance.

## 中文

Art 现在明确决定原生编辑边界。Art 计划 2.2 为每个实际对象声明唯一
native_name 和 render_separately:true；可选 native_group_path 让不同子对象
一起移动，同时保留分别编辑的能力。Art 根据独立选择、移动、宽度与格式调整
的实际需要决定边界，重要选择用已有 purpose／work-notes 记录。

Copy 仍按内容包 3.3 只交干净文字，多段正文可以共用 Art 明确声明的单个文本框。
不会恢复 Copy 逐段单独渲染、同级同样式或文字顺序绑定视觉顺序。

Output 必须保留 Art 声明的对象、原生类型与准确分组，不得擅自合并、拆分、
改组或拍平；边界变化回 Art。实际 PPTX 比对和 QA 同时检查文字区间与真实对象。
Supervisor 在既有 native_editability 观察中记录编辑保真和边界是否适用，
不新增审批表或审美配额。

旧 Art 2.1 保留按原版本回读。新增共框、独立对象、原生分组、擅自合并／改组、
图片拍平替代的回归；Release CI 的真实 LibreOffice 回读渲染补充原生分组内的
独立可编辑子对象，不冒称 PowerPoint／WPS 原生应用验收。
